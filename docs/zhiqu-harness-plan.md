## 目标形态

现在的 zhiqu CLI 是后端的遥控器：读 / 写 / 跑命令都在服务器上执行，后端一放远程就碰不到本机项目。
harness 反过来：

```
你的电脑（npm 包 zhiqu，Node）                    远程服务器（现有 Spring 后端 + MySQL）
├─ agent 循环                                   ├─ 登录与令牌
├─ 本地工具：读 / 搜 / 写（diff 确认）/ 运行        ├─ 模型网关：API Key 只在这里，流式转发，
├─ 权限确认                                     │   按模型的上下文窗口裁剪，计量用量
├─ 项目说明文件、Skills、MCP 客户端               ├─ 对话存档（网页里也能看到）
├─ 长对话压缩                                   └─ 远程工具：Wiki / 学习计划 / 长期记忆
└─ 终端界面：Markdown 渲染、每一步过程、diff                （仍是草稿，确认后才落库）
```

**已定的取舍**（2026-09-24 用户选择）：

- 循环与工具在**客户端**（真 harness），不是服务器循环委托工具。
- 先**不发布**到 npm，本地 `npm link` 使用；P7 真正发布前单独确认。
- 本地工具的安全规则要用 JS 再实现一份（路径不逃出工作区、解开软链、不读 `.env` / 密钥、
  禁行内代码、不继承环境变量、超时、输出上限）。防分叉：Java 与 JS **共用一份一致性用例**
  （同一个 JSON，同样的输入必须得出同样的放行 / 拒绝），两边的测试都跑它。
- npm 包用零依赖的 ESM JavaScript（Node ≥ 18 自带 fetch / readline / child_process / node:test）。

## 用户补充（2026-09-24）

- **`/resume`**：在同一个工作区里回溯不同的聊天记录。用工作区里的 `.zhiqu/` 文件夹实现：
  `.zhiqu/setup.json` 记会话索引（标题、时间、条数），每段会话的完整记录在 `.zhiqu/sessions/<id>.jsonl`。
  归入 P2（会话续接）。`.zhiqu/.gitignore` 忽略 `sessions/` 与 `setup.json`（个人聊天记录），
  `.zhiqu/skills/`、`mcp.json` 可以提交共享。

- **三档权限 = plan / 确认 / auto**（2026-09-24）：原来的「只读 / 读+写 / 读+写+运行」三档在 harness 里改成
  - **只读 → plan 模式**：只读、只搜、只出计划，不写不跑；计划给出后问要不要开始做（可直接切到下面两档）；
  - **写 → 逐个确认**：每次写文件先给 diff、每条命令先给命令行，问 y/n（可选「本会话都允许」）；
  - **运行 → auto**：写文件、跑命令都不再问，**做完了再告诉用户**（每一步照样显示、diff 照样打印）。
  安全规则（不出工作区、解开软链、不读密钥、禁行内代码、不继承环境变量、超时、输出上限）三档都照样生效 ——
  auto 免的是「问」，不是「规则」。归入 P2（本地工具、权限确认）。
  由来：用户在旧 CLI 里一再遇到「生成草稿 → 回答先说请确认 → 再按 y」，说「应该写完了再告诉我，这就是和其他 coding agent 的区别」。

- **npm 包自己的配置在 `.zhiqu/` 下，里面保留一份系统内容**（2026-09-24）：
  - 用户级 `~/.zhiqu/config.json`：服务器地址、令牌、默认模型、默认档位（与旧 Java CLI 的 `cli-token` 分开）；
  - 项目级 `<工作区根>/.zhiqu/settings.json`：同样的键，覆盖用户级；
  - **系统内容**：第一次运行时把内置系统提示写成 `~/.zhiqu/system.md`（只写这一次，之后不覆盖，用户可以改）；
    工作区的 `.zhiqu/system.md` 优先。`/system` 显示正在用哪一份，`/system reset` 重写成内置版本。
  （按这个理解实现；「系统内容」若另有所指，以用户更正为准。）归入 P2。

## 名词说明

- **P1 的「Wiki / 计划 / 记忆远程工具」**：zhiqu 作为学习系统自己的能力 —— 查知识 Wiki、
  把判题失败记进「薄弱点」页、把项目里程碑排成日历任务草稿、长期记忆。数据在服务器数据库里，
  所以工具**在服务器上执行**，不装进 CLI；CLI 只知道工具名，调用时把请求转给服务器。
  写类操作仍是草稿，用户在网页里确认后才落库（与现有纪律一致）。
- **个人访问令牌**：CLI 登录后拿到的长期令牌，只能访问 harness 用的接口，可在个人中心撤销；
  之后请求不再带密码。
