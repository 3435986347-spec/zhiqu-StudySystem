# 迷你番茄钟计划（2026-10-08 草案；2026-10-09 用户定了）

## 由来

用户 2026-10-08（第四十七轮 review 途中）：「step5之后我的设想是，桌面端app可以缩小变成一个番茄钟计时器的形式，就跟网易云音乐缩小到桌面歌词的形式差不多，都是缩小版，然后甚至说这个番茄计时器还可以变成一个宠物类型，当然这是后话」。

这份是「缩小成一个悬浮的番茄钟」的方案；宠物形态是后话，不在这一份里（做法上留了口子，见最后）。

## 现在的番茄钟是什么样（先要补的一块）

- 番茄钟只在看板页上，计时的状态（还剩多少、结束时刻、关联哪个任务）**只在那一页的内存里**：在看板上开始一个番茄钟，切到 AI 助手页，它就没了（不会记一次专注，也不会到点提醒）。
  这对现在的网页也是个坑；对迷你窗更是前提 —— 迷你窗和主窗口要看到同一个钟。
- 记录已经有离线补记（`recordPomodoro` 的待补记）、到点有声音 + 系统通知（第二十五轮，桌面应用走原生通知）。

## 想法（大致做法）

1. **番茄钟的状态存下来、全站共用**：开始时把「结束时刻、时长、关联任务」写进 localStorage，计时按结束时刻算（第二十一轮的做法照旧）；
   任何一页打开都接着同一个钟（侧栏或页头一个小小的「专注中 18:42」），到点由还开着的那一页记录、提醒（几个标签页用锁排队，第四十七轮的那一套）。
   离开看板不再丢番茄钟 —— 这一步网页、桌面应用都受益，可以先做。
2. **桌面应用的迷你窗（macOS 外壳）**：一个小的悬浮面板（`NSPanel`：总在最前、不抢焦点、所有桌面空间都在、可以拖到屏幕任意位置、记住位置），
   里面是一个小网页 `mini.html`（同一个登录、同一份 localStorage —— 和主窗口看同一个钟），显示倒计时、开始 / 暂停、展开回主窗口。
   外壳的改动要重新打包才到手里。
3. **怎么进出迷你模式**：番茄钟卡片上一个「缩小到桌面」按钮（只在桌面应用里出现）；迷你窗上一个「展开」回到主窗口。是否「主窗口最小化时自动变迷你」—— 要你定。
4. **网页版（可选）**：Chrome / Edge 有「文档画中画」（Document Picture-in-Picture），网页也能开一个总在最前的小窗；Safari 不支持。要不要做 —— 要你定。

## 要你定

1. **范围**：只做 macOS 桌面应用（建议），还是网页（Chrome 的画中画小窗）也做？Windows 版桌面应用另说（它是 jpackage 打的，外壳不一样）。
2. **怎么进入迷你模式**：番茄钟卡片上的「缩小到桌面」按钮（建议）；还是主窗口最小化时自动；还是两样都要。
3. **迷你窗里放什么**：只有倒计时 + 开始 / 暂停（最小）；还是再加关联的任务名、今天第几轮（建议）。
4. **样子**：半透明的深色胶囊（像网易云的桌面歌词，浮在什么背景上都看得清）；还是跟着浅 / 深色走的小卡片。

## 步骤（定了之后，每一步一轮）

| 步 | 做什么 |
|---|---|
| 1 | 番茄钟状态存下来、全站共用（离开看板不丢；任何一页都看得到「专注中」；到点只记一次、只提醒一次） |
| 2 | `mini.html`：迷你番茄钟的小页面（浅 / 深、窄到 240px 也放得下） |
| 3 | macOS 外壳：悬浮面板、进出迷你模式、记住位置；重新打包 |
| 4 | （定了要的话）网页的画中画小窗 |

## 宠物（后话）

迷你窗的内容是一个网页，以后要把倒计时换成一个会动的小宠物（专注时安静、到点了伸懒腰、连续几轮之后长大……）只换 `mini.html` 里画的东西，外壳不用动。

## 用户定了（2026-10-09）

1. **范围**：只做 macOS 桌面应用（网页的画中画不做）。
2. **进入**：番茄钟卡片上的「缩小到桌面」按钮；迷你窗上「展开」回主窗口（最小化时不自动变）。
3. **内容**：倒计时、开始 / 暂停、关联的任务名、今天第几轮（第 3 问没单独问，用的是方案里建议的那一档）。
4. **样子**：半透明的深色胶囊（像网易云的桌面歌词）。

所以步骤是上表的 1、2、3，第 4 步不做。
