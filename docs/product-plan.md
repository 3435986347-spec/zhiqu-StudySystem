## 二、定位变了，判断跟着变

锐评里我说「范围失控」：一个学习计划工具带着多 agent 编排、RAG、coding agent、仿 Claude Code 的命令行。
**按「AI 办公助手」的定位，这些不再是范围失控，而是产品的主体**：AI 助手（对话、资料、检索、Wiki、计划草稿、长期记忆）是中心，
coding agent 和命令行是它在「干活」方向上的延伸。

真正的问题换成了两个：

1. **产品的外壳还是学生学习系统。** 名字、标题、导航、文案、分类、成就、统计口径都在对学生说话。一个上班的人打开它，看到的是「考研」「六级」「学习时长」。
2. **主流程没有人走过，而且主流程本身也变了。** 原来以为主流程是「建任务 → 收提醒 → 番茄钟 → 看统计」；
   按新定位，**主流程是 AI 助手那一条**：配好模型 → 把资料交给它 → 问问题、让它出计划 / 写 Wiki → 确认草稿 → 变成任务和提醒。
   一个新用户第一次能不能顺利走通这一条，没人试过 —— 比如新账号默认有没有可用的模型（系统模型要部署方配 `ZHIQU_SYSTEM_AI_API_KEY`，没配时新用户第一句话会怎样）。

其余几条锐评照旧成立：死代码和假数据靠测试站岗、单文件前端拖慢一切、`CLAUDE.md` 成了日记、节奏超过能审查的速度。

## 四、要你定（做到第 3 步之前问；我的建议写在后面）

1. **个人还是团队？** 「办公软件」常常意味着多人：共享任务、共享知识库、成员与权限。现在是单人账号 + 一个管理员，团队是一个很大的新方向（数据模型、权限、通知都要变）。
   **建议**：先做好「个人的 AI 办公助手」，团队放到之后单独立项。
   **已定（2026-10-04）：先做个人。**
2. **名字和文案。** 「知趣·象限」留不留？「自主学习系统」肯定要换。
   **建议**：保留「知趣·象限」（四象限仍然是任务管理的核心），副标题换成办公方向的说法，具体措辞你定。
   **已定（2026-10-04）：保留「知趣·象限」，副标题我拟几个给你挑。**
3. **学生味的功能去留。**
   - 番茄钟、例行计划、四象限：办公同样用得上，**留**，只改文案。
   - 「学习统计」：**改成「专注 / 工作统计」**，口径从「学习时长」改成「专注时长」。
   - 「成就系统」：偏游戏化、偏学生。**建议先从导航里收起来**（数据不删），看有没有人要。
   - 「参考计划」的分类（考试备考 / 语言学习……）：**改成办公方向的模板分类**，或者先换成用户自己定义的标签。
   **已定（2026-10-04）：四条都照做** —— 学习统计改专注 / 工作统计、成就从导航收起（数据不删）、参考计划改办公模板分类、番茄钟 / 例行计划 / 四象限只改文案。
4. **主要部署形态。** 桌面单机（数据在自己电脑上）还是服务器多用户？两者对 coding agent 的意义不一样：工作区现在只在回环地址上、只给管理员开（读的是服务器的磁盘）。
   **建议**：以桌面 / 本机为主（AI 读写自己电脑上的文件是办公场景的核心价值），服务器版保留但不在上面开工作区。
   **已定（2026-10-04）：桌面 / 本机为主。**
5. **提醒怎么到达。** 现在只有 PushPlus / 企业微信群机器人 / QQ 三种第三方推送，页面开着的时候也不会弹任何东西。办公场景里企业微信合适，但新用户要先去第三方申请凭据。
   **建议**：加一个「页面开着时在页面里提醒」（浏览器通知），第三方推送作为「离开电脑时」的补充。

6. **只说「安排一下」要不要也出计划？**（第二十三轮走出来的）现在要说「制定 / 生成 / 添加」才把计划建成任务草稿 —— 门是故意窄的：过触发会弹一个没要的确认框。
   **建议**：改成把计划工具交给模型、由它判断这一句是不是要建任务（AI 助手的定位下，靠关键词猜意图会一直漏）；代价是带计划词的消息多一次模型调用。
   **已定（2026-10-03）：让模型判断。** 做完：第二十五轮（`docs/rounds/round-25.md`）—— 没有建任务的动词时把计划工具以 `tool_choice: auto` 交给模型，它不调就是不要。
7. **页面里的提醒要不要响 / 弹系统通知？** 番茄钟到点、任务提醒到点，页面开着时现在只改标签页标题、弹一条页面内提示。浏览器通知要用户授权一次。
   **建议**：做，和第 5 条一起（同一套授权）。
   **已定（2026-10-03）：做。** 做完：第二十五轮 —— 页面开着时到点响一声 + 系统通知 + 页面内提示（不看第三方渠道发没发出去，第 5 条的「页面里提醒」也就有了）；桌面应用走 macOS 原生通知（WKWebView 里网页通知的授权一请求就是「拒绝」）。
8. **新开标签页要不要保持登录？** 没勾「记住登录状态」时登录态只在当前标签页（sessionStorage），新开一个就要重新登录。
   **建议**：同一个浏览器会话里共享（关浏览器才失效），「记住」仍然管跨重启。
   **已定（2026-10-03）：同一浏览器会话共享。** 做完：第二十五轮 —— 标签页之间借令牌；退出、改密码只动拿着同一张令牌的标签页。
