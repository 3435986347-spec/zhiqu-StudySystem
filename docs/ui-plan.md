# 界面打磨计划（2026-10-06）

## 由来

用户 2026-10-05：「看着整个页面的 ui 布局感觉很玩具和幼稚，一点也不细致和高级，就是在细节方面的处理」，看了锐评之后：「plan，switch ui text to system sans-serif to all」。
字体那一半第三十九轮已经做了（文字一律系统无衬线、去掉 Google Fonts、数字用等宽数位）；这份是其余部分的计划。

## 现在是什么样（2026-10-05 量的，`zhiqu-backend/src/main/resources/static/` 下全部页面、壳、模块、样式表）

根子是**没有设计体系，每个元素都是手调的**：

| 量 | 现在 | 说明 |
|---|---|---|
| 不同的字号 | 26 种 | 用得最多的是 11.5 / 12 / 12.5 / 13 / 11 / 10.5px，主力字号小、挤，相邻两级只差半个像素 |
| 不同的 padding | 103 种 | gap 从 1px 到 20px 几乎每个整数都用过 |
| 内联 `style=""` | 817 处 | 512 处在 JS 字符串里拼；值不共享，所以对不齐 |
| 圆角 / 阴影 / 字重 | 17 / 14 / 6 种 | 字重里有 650、800 |
| 次要文字对比度 | 约 2.7 : 1 | `--zq-text3`（#8D99A8）在页面底色上；WCAG 要 4.5 : 1，而它正好用在 11px 的标签上 |
| 图标 | Unicode 符号 | ✦ ▦ ☰ ↻ ❏ ≣ ◈ ⌘ ∿ « …… 每个来自不同字体，粗细、基线都不一样 —— 「玩具感」最直接的来源 |
| 主题 | 5 套 × 明暗 = 10 套配色 | 设计没定下来的信号，每一套都做不精 |

各页的具体问题（截图在第三十九轮的会话里）：
- **侧栏**：「« 收起」做成一整条描边按钮放在导航最上面，比导航项还显眼；导航图标是上面那些符号。
- **AI 助手（首页）**：页面标题「AI 助手」下面卡片头又写一遍；「已同步 50 条历史消息」这种调试信息摆给用户看；两侧收起的面板是竖排文字；
  输入区一条常驻的虚线拖拽框 + 一排 6 个小按钮（上传 / 输入 / 联网 / 深度思考 / 模型 / 发送）—— 像表单，不像现在通行的那种一个大输入框、工具收在框里。
- **看板**：周历每天 5 个一模一样的灰块「08:00 例…」截到只剩一个字，没信息还很重；「逾期未完 132」大红数字。
- **任务**：五个下拉 + 「查询」按钮，像老式后台模板；绿色描边的「新建任务」挨着蓝色的「查询」，颜色没有语义。
- **设置弹窗**：左栏留白大，右边四个字段占不到一半高度。

## 目标

细致、克制、像一个认真做的工作软件：一套字阶、一套间距、几个圆角和阴影、一套线性图标、对比度达标；每个组件只有一种写法（CSS 类），不在页面里手调。

## 要你定（开工前）

1. **参照的风格**：我的建议是**克制的中性风**（参考 Linear / Notion / Claude 的桌面应用：大面积留白、灰阶层次、一个强调色、细线条图标）。你有更具体的参照就照你的。
2. **主题**：5 套 × 明暗 → 我建议**留 1 套（石墨蓝，现在的默认）+ 暗色**，其余四套下线（设置里不再出现；已经选了别的那几套的人回到默认）。
3. **第一步做完先给你看**：第 1、2 步做完后，侧栏 + AI 助手两页的前后对比截图（1440 宽、手机宽、明暗各一张）给你确认方向，再铺到别的页面。

## 步骤（每一步一轮，计划和结果照例存 `docs/rounds/`）

| 步 | 做什么 | 怎么算做完 |
|---|---|---|
| **1 设计令牌** | 字阶 12 / 13 / 14 / 16 / 20 / 24（+ 展示用 30）；间距 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40；圆角 6 / 10 / 14 + 全圆；阴影两级；字重 400 / 500 / 600；颜色修对比度（次要文字 ≥ 4.5 : 1）。组件类：按钮（主 / 次 / 幽灵 / 危险 × 两个尺寸）、输入框、下拉、卡片、徽标、表格、页签、分段控件、空状态、骨架。 | 令牌只在 `zhiqu-ui.css` 定义一次；判据：组件类都在、对比度（算出来的，不是写死的期望值）达标 |

每一步都做：内置浏览器里 1440 宽 / 375 宽、明 / 暗的前后对比截图；新判据见过红；全量；桌面应用重新打包；换缓存令牌。

## 不在这份计划里

- 页面之间改成应用内切换（侧栏不动、只换内容区，不再整页加载）：比第三十九轮的交叉淡化更顺，但要给每一页写「离开时收拾」（AI 的流、Wiki 的历史和草稿、番茄钟的计时），是另一件事，要做的话单独立项。
- AI 助手很长的历史一次排版的开销（第三十九轮试过 `content-visibility`，撤了：加载更早的消息时位置会跳）。

## 用户定了（2026-10-06）

「中性风，然后我个人是比较喜欢金色，其实其他的颜色也不错，要不试一下就换回黑色和白色？（按照白天白色，晚上黑色）。然后做完第一步给我先看」

- **风格**：中性风。
- **主题**：5 套 × 明暗收成**一套中性配色、白天白色、晚上黑色**。白天 / 晚上**跟着系统的外观走**（用户的 Mac 设的是「自动」，日落之后系统自己切到深色 —— 2026-10-06 查过 `AppleInterfaceStyleSwitchesAutomatically = 1`）；
  菜单里仍可手动固定成浅色或深色。
- **强调色**：用户偏好金色；也说「其他的颜色也不错」「要不试一下就换回黑色和白色」—— 第 1 步做**金色**（默认）和**纯黑白**两版，截图里并排给用户挑。
- **确认点提前**：第 1 步（设计令牌）做完就停，给用户看截图（原计划是第 3、4 步之后）。
