# 第五十轮（2026-10-09）：迷你番茄钟第 2 步 —— `mini.html`，迷你番茄钟的小页面

## 由来
`docs/mini-pomodoro-plan.md` 第 2 步（用户 2026-10-09 定了：只做 macOS 桌面应用、半透明的深色胶囊、放倒计时 / 开始暂停 / 关联的任务名 / 今天第几轮）。
第 1 步（第四十九轮）把番茄钟挪进了壳、存在 localStorage —— 迷你窗是另一个网页，登录、存储和主窗口是同一份，看的就是同一个钟。
第 3 步（下一轮）是 macOS 外壳：悬浮面板装这个页面、「缩小到桌面」/「展开」、记住位置。

## 计划
1. **`mini.html` + `assets/pages/mini.js`**（页面模块，和别的页一样经 `route()` 启动）：一个胶囊 ——
   左边一个圆按钮（开始 / 暂停，外圈是进度环），中间大字的倒计时、下面一行小字「关联的任务 · 今天第 N 轮」（太长就省略号），右边一个小的「展开」按钮。
   状态：待开始（时长照上一次的，没有就 25 分钟）/ 专注中 / 已暂停 / 专注结束（休息一下）。按钮交给壳的 `pomo`（和看板的卡片同一套）。
2. **样子**：半透明的深色胶囊（像网易云的桌面歌词，浮在什么背景上都看得清）—— 不跟着浅 / 深色变；页面本身透明（第 3 步的悬浮面板是透明窗口，只露出胶囊）。
   窄到 240px 也放得下（任务名先省略、再藏起来），高 56px 上下。不要侧栏、不要页面头部。
3. **展开**：桌面应用里告诉外壳（第 3 步接上 `zqMini` 这座桥）；浏览器里直接去看板。
4. **没登录 / 登录过期**：迷你窗里不跳登录页（一个胶囊里塞不下），写一句「在主窗口登录后再用」。
5. **今天第几轮**：壳的 `updatePomoCount` 原来要求页面上有「今日：N 个」那一块才算，迷你窗只有「第 N 轮」—— 两块各自有就各自填。
6. **判据**：`mini-check.js` 在 node 里真跑 `mini.js` 的画法（四种状态、任务名、按钮交给壳、展开走桥还是去看板）；按页面扫的那批判据（页头、侧栏、示例数据、缓存令牌……）逐条看：
   迷你窗该守的守，不该守的（没有侧栏、没有页头）写明为什么放过。扰动见红。
7. 真浏览器：开着看板和迷你页两个标签页，一边开始 / 暂停另一边跟着；窄到 240px；深浅两种系统外观下胶囊都一样；暴力连点。截图给用户；全量；桌面应用重新打包（外壳这一轮不改，页面跟着 jar 走）。

## 结果（2026-10-09）

照计划做完；真浏览器里照出一处（新页面打不开）和两处小样子，一起改了。

- **`mini.html` + `assets/pages/mini.js`**：一个胶囊 —— 左边圆按钮（开始 / 暂停，外圈是进度环），中间倒计时（20px）、下面一行小字「任务名 · 今天第 N 轮」，右边「展开」。
  四种状态：待开始（照上一次的时长和任务，什么都没做过就 25 分钟、不关联任务）/ 专注中（小字是任务名，没有就「专注中」）/ 已暂停（时间变灰）/ 专注结束。
  按钮交给壳的 `pomo`（和看板的卡片同一个钟：一边按暂停，另一边一秒内跟上）；按钮上的提示只在变了的时候换。
- **样子**：半透明的深色胶囊，颜色是 `--zq-mini-*` 四个令牌、浅深两块写一样的值（不跟着明暗变；对比度判据里加了两对）；页面透明；
  `html.zq-mini-page` 的选择器压过手机宽那段 `@media` 给侧栏让的 56px（这个窗口比手机还窄）。240px 宽时任务名先省略、「第 N 轮」不动。新图标 `play` / `pause` / `maximize-2`。
- **展开**：有外壳的桥（`webkit.messageHandlers.zqMini`，第 3 步接）就告诉外壳，迷你窗自己不跳；浏览器里去看板；桥坏了也去看板（不是点了没反应）。
- **没登录 / 登录过期**：不换成登录页（`redirectToLogin` 对迷你页只挂一个 `zq-signed-out` 类），胶囊里写「在主窗口登录后再用」，「展开」还在。
- **今天第几轮**：`updatePomoCount` 原来没有「今日：N 个」那一块就整个不做，现在两块各自有就各自填。
- **照出来的（真浏览器）：新页面一打开是一片空白** —— `SecurityConfig` 的放行清单是一页一页列的，`mini.html` 不在里面，没登录的请求拿到 403、没有正文。
  加上，并新加一条判据：`static/` 下每一个 HTML 都要在放行清单里（`MiniPomodoroTest`；原来没有任何判据管这件事）。CLAUDE.md 的前端规矩里记了一行。
- **小样子**：圆头的线长度是 0 时也画出一个点 —— 待开始时环顶上一直有个白点（看板的环原来就有），没走的时候整条藏起来；做完时小字「专注结束，休息一下」在 300px 宽时被截断，改成「专注结束」。
- 迷你页登记进 `PAGE_MODULES`、`service-worker.js` 的核心资源。

**判据**：新的 `MiniPomodoroTest` 三条 —— `mini-check.js` 16 条（真跑 `mini.js` 的画法和按钮，再抠出壳的 `updatePomoCount` 看只有「第 N 轮」时也填得上）、每一页都放行、接线；
