## 摸底
- 现在点表格：整张表换回原文（一堆竖线横线），第八十三轮起光标落在点的那一格、点的那一行留在鼠标底下，但还是改原文。
- Obsidian：表格一直画着，点进一格就在那一格里打字；Tab 走到下一格。
- CodeMirror 对块（widget）的规矩：块说「这类事件我自己管」（ignoreEvent），键盘、输入、选区变化编辑器都放过去；块里的 DOM 变化编辑器不解析
  （DOMObserver.readMutation 遇到块就跳过）；原文变了、块的 eq 不等时先问 updateDOM，回 true 就留着原来的 DOM。—— 够在格子里直接改。

## 计划
1. 表格换成专门的块（TableWidget）：格子 contenteditable（plaintext-only）。点进一格：那一格换成它的原文（**加粗** 这些符号露出来），光标照点的地方放；
   打字同步改原文里那一格（| 自动转义、换行变空格），自己改的那一下不重画整张表（焦点不丢）；离开这一格照阅读的样子画回去。
   Tab / Shift+Tab 下一格 / 上一格，回车到下一行同一格，最后一行再回车 / Esc / 最后一格 Tab：光标出到表格下面。⌘Z / ⌘⇧Z 走整篇的历史。
   点表格边上（不在格子里）照旧换回原文改；只读时格子不能改。
2. 纯函数（格子在原文里的范围、写回去的转义）node 里测；接线按源码钉；内置浏览器和桌面应用（WebKit，真键盘）里真改一遍，看原文、自动保存、撤销。
3. 判据先红、扰动见红；全量（第八十四轮的一起）；换缓存令牌；两轮一起提交推送。

## 结果
- 表格换成 `TableWidget`：格子 `contenteditable="plaintext-only"`（只读时不能改）；`ignoreEvent` 对格子里的事件回 true —— 键盘、输入、选区变化编辑器都不管；
  点进一格：那一格换成原文（`**李四**` 露出符号），光标照点的地方放；打字同步改原文里那一格（`tableCellRange` 找范围、`tableCellSource` 转义 | / 换行变空格），
  `_zqSelfEdit` 让自己改的那一下 `updateDOM` 留着 DOM（焦点不丢）；别的改动（撤销、别处改了这张表）重画、正在改的那一格接着改；离开一格单独画回阅读的样子。
  Tab / Shift+Tab、回车（下一行同一格；最后一行出到表格下面）、Esc（出到表格下面）、⌘Z / ⌘⇧Z（整篇历史）。点表格边上（不在格子里）照旧换回原文、点的那一行不挪。
  原来那个画表格 / 图片的块只剩图片。容器不再挂 `.zq-md`（renderMarkdown 自己包了一层；markdown-check.js 抓到「别处借用 Markdown 的类」）。
- 内置浏览器真鼠标真键盘：点进「张三」那一格打「丰」「|」→ 原文「| 复盘 | 张三丰\| | 进行中 |」，表格一直画着、焦点没丢；Tab / Shift+Tab / 回车走对格子；
  加粗那一格点进去露出 `**李四**`、离开画回 `<strong>`；Esc 出到表格下面一行；⌘Z 两次撤回到「张三」、表格跟着重画；三次修改都自动存上（「已保存」）。
- 判据：wiki-cm-check 加 3 条（格子范围、写回去的转义、TableWidget 的接线）；WikiEditingFeelTest「点进画出来的块」改成表格边上那条路
  （第一遍它在没扰动时也会抛越界：拿一段注释当结束标记，判据先把注释去掉了 —— 改成拿代码当标记）。扰动 9 处全红。

## review（第八十四、八十五轮，用户：「做完后review，review不出问题后接着做下一轮」）
找到四处，都修了：
1. **点圆点光标不进去**：列表的 `- ` 画成圆点以后，圆点是个不管点击的小块（`ignoreEvent` 默认 true），点它光标落到别处。改成 `BulletWidget`：按下去光标放到这一项「- 」后面。
   内置浏览器真鼠标点第二个圆点 → 光标在「- 第二项」第 2 列。
2. **页名删空就整个不见**：`.zq-wiki-inline-title:empty{display:none}` 不管是不是正在改，删到空的那一下页名连同光标一起没了，再打的字没地方去。
   第一次改成 `:empty:not(:focus)` 还不够 —— 窗口没有焦点时（面板藏着、切到别的应用）`:focus` 不成立，正在改的页名照样被藏，藏的时候不发 blur，原名回不来。
   最后改成看「能不能改」：改不了的空页名才藏，能改的删空了显示灰的「无标题」。
3. **「无标题」画不出来**：真键盘删空以后浏览器在里面留一个 `<br>`，`:empty` 不成立。输入时只剩 `<br>` 就清掉（还有字时不动，不然光标跳到开头）。
   内置浏览器真键盘：删空 → 灰的「无标题」、光标在它前面；打回原名、回车 → 页名回来、光标进正文、「已保存」。
4. **页名节点找不到时这一页从此没页名**：第一次找页名节点时正文区要是已经被整个换掉，`wikiTitleEl()` 拿到 null。找不到就自己建一个。
- 判据：wiki-cm-check 加 2 条（圆点的接线、删空清 `<br>`）、WikiLookTest（只藏改不了的、「无标题」）、WikiEditingFeelTest（找不到就建）；扰动 8 处全红
  （第一遍「圆点不管点击」绿：扰动加了个无关的方法、没删 `ignoreEvent`，改准了再跑红）。缓存令牌 `20261031-r85b`。
