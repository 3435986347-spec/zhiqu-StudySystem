# 第六十四轮（2026-10-14）：Obsidian 知识库 ZIP、图片与侧栏动画

## 用户要求

- Wiki 支持一个根文件夹下的 Markdown 文件与附件 ZIP 导出；ZIP 导入自动识别目录和笔记关系，接近 Obsidian vault 存储方式。
- Wiki 可插入图片。
- AI 助手与 Wiki 左右两侧面板展开/收起有流畅动画。
- ZIP 导入弹窗的「选择文件」按钮更美观。
- AI 助手和 Wiki 的侧栏内容滚动后，顶部收起按钮仍可见。
- 现有上传文件解析来源入口保留，在此之外新增功能；本轮同样记录 round。

## 计划

- 检查既有 Markdown ZIP、parentId 目录、双链和图片编辑/渲染链路，在它们基础上完成可往返的 vault。
- ZIP 导入先预览，识别层级、链接、图片和冲突，明确确认后再写入；未知/不支持文件与歧义如实提示。
- 图片作为个人私有附件持久保存，展示与导出按用户隔离，不通过公共 uploads 暴露。
- 侧栏宽度/内容过渡兼容 WebKit，处理连续切换、移动端覆盖、焦点和减少动态效果偏好。
- 行为判据先见真正 assertion red；Maven 共用 target 串行，接口变化最后 JDK17 clean。浏览器使用临时内存服务与公开示例，更新缓存令牌和相关首页截图。

不下载安装 Docker，不调用真实模型，不启动/重启用户桌面应用，不修改真实 Wiki/任务数据。

## 实现记录

- Wiki 页头新增「导入知识库」和「导出 ZIP」。导入 ZIP 先解析并显示将新增的笔记、附件、双链数量、目录及警告；用户明确点「确认导入」后写入。可放在 Wiki 根目录或当前普通页之下，按当前父页版本校验；确认时重新解析、重新检查目录与重名，并用预览令牌拦住预览后的变化。重名新增，不覆盖旧页；系统页不能作为导入父页。确认上传使用幂等键。
- 导出可以选整个 Wiki 或当前页及其子页。压缩包统一以 `wiki/` 为根，Markdown、图片与普通附件保留在文件结构中；笔记带少量 `zhiqu_vault` 元数据以便往返保存标题和类型。导入识别 Markdown 目录、Obsidian 双链及图片嵌入、标准 Markdown 链接；能解析的链接重写到新知识页或私有附件，无法确定的引用保留原文并在预览中提示。`.obsidian`、`.git`、macOS 元数据不作为知识内容导入；JSON 等其他文件当普通附件保存，不执行内容。
- `V44__private_wiki_attachments.sql` 新增按用户归属的加密附件表。图片上传校验实际图像格式和尺寸，正文可经工具栏、粘贴或拖入插图；查看时先鉴权再取 Blob。普通附件通过鉴权下载。Markdown 渲染支持私有图片、`![[图片|宽度]]`、附件链接和双链别名/小节；编辑与保存保留图片 Markdown。导入确认的页面、关系和附件同一事务写入。
- AI 助手与 Wiki 的左、右侧栏加入宽度与内容过渡；连续快速切换、窄屏和减少动态效果偏好有对应处理。展开侧栏内部滚动时，收起按钮 sticky 在面板顶部。ZIP 文件输入改为图标按钮，并在旁边显示所选文件名与大小。
- 最终审查修复了显式目录引用误连、带括号文件名的 Markdown 图片解析、导入成功但刷新目录失败时的误报，以及导出限额检查前加载过多附件的内存风险。刷新失败会明确提示已导入并建议刷新页面；导出逐页和逐附件检查预算。新增判据都先在旧实现得到 assertion failure，再于修复后通过。
- 桌面 `risk` 仅作为格式参考检查结构，不读取或提交用户真实笔记：24 个 Markdown、11 个 PNG、4 个 JSON；其中包含有空格的文件名、双链和带宽度的图片嵌入。测试素材另造合成样本。
