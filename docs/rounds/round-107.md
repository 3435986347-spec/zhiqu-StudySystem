# 第一百零七轮（2026-11-06）：AI 助手输入框下面的选择刷新后还在；档位面板去掉小字

## 由来
用户 2026-11-06：「每次刷新后ai助手下面的模型就会回到默认模型，深度思考等状态也没有保留，很影响体验」「去掉档位下面的小字」。
- 现在模型下拉每次打开都是「默认模型」，联网、深度思考每次打开都写死关着（第二十几轮的取舍是「按轮计费或变慢，默认关着更稳妥」；用户现在说这样影响体验）。选的 Notebook 是记住的（`zq-ai-notebook`），这三样没有。

## 计划
1. 记住模型、深度思考、联网：存这台浏览器的 localStorage（`zq.ai.composer.<用户 id>`，按用户分开：模型 ID 是各人的，公用电脑上换个人登录不接上一个人的）。桌面应用端口固定（47615），重开也在。
   记的模型不在列表里了（被删了）回到默认；列表没取回来不擦掉记的；存不了（隐私窗口）、存的是坏数据都不炸，只管这一页。退出登录不删（不是内容，重新登录还接着用）。
2. 档位面板只写名字（close / plan / manual / auto），每档的说明挪到悬停提示；面板收窄。
3. 判据先红（发布的那一段放到 node 里真跑）；真浏览器（验证库）里选、刷新、再刷新、看发出去的请求，连点的暴力测试；换缓存令牌。

  联网也一起记了（用户说「深度思考等状态」）：原来的取舍是联网按轮计费，默认关着更稳妥；现在按下的样子一直看得见，自己关。

- 按用户分开，换个人登录不接上一个人的。存不了（隐私窗口、配额满、`localStorage` 一碰就抛）、存的是坏数据（坏 JSON、数组、null、`{"think":"1"}`）都不炸，当页照样能按。还不知道是谁（`state.user` 没有）不写。退出登录不删。
