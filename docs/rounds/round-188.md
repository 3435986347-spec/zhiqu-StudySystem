# 第一百八十八轮（2026-11-26）：这一轮留一个浏览器

`docs/harness-next-plan.md` 画面第 V3 步。用户已定：可以打开本会话后台命令拉起的 `127.0.0.1` / `localhost`。

## 计划

Chrome 用调试端口自己说 CDP，不引 Playwright。同一轮里留着这一个进程，回合结束杀掉。能按顺序等待、点击、拖动、按键。`frames` 取 2 到 4 时隔 200 毫秒连拍，帧差用亮度格算，进上下文的是数字，图只附最后一张。拿掉写死的 5 秒虚拟时间。先试本机 GPU，WebGL 上下文起不来再退回 SwiftShader，结果里写明用了哪一种。只有系统 WebKit 时仍是截完就关的一张图，不假装能点。别的网址不打开。

## 结果

「还写着虚拟时间」先红，再从一次截一张的参数里拿掉。帧差被改成恒 0 时，全黑到全白对不上 9。调试端口用本机套接字对过文本帧。常驻会话的假连接上看见：metal 没有 WebGL 就关掉再起 SwiftShader；点击、拖动、按键的事件顺序对；两张一样的图帧差是 0。系统 WebKit 拒绝连拍。主回合结束关浏览器，子 agent 那一回合不关。

这台机器 `findChrome()` 只有 `~/.zhiqu/preview/zhiqu-webkit-shot`，没有 Chrome，真浏览器没跑。
