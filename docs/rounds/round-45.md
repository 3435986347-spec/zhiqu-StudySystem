# 第四十五轮（2026-10-06）：命令行找不到「目标」页；悬停提示；Wiki 目录头上叠字；首页轮播

## 由来
用户看过第四十四轮的截图、重新打包试过之后（2026-10-06）：
1. 截图：知识 Wiki 左边「目录」那一行，右边的页数「4 页」和收起图标叠在一起。
2. 「鼠标悬停的时候也没有显示名字」—— 第四十四轮把两侧面板的开关做成只有图标、名字放在 `title` 里，桌面应用里悬停什么都不出。「其余做的不错」。
3. 「还有主页轮播图需要改一下」。
4. 「我明明有目标页面，就是27考研」—— 命令行 `zhiqu` 里问「我现在有哪些计划」，模型说任务没有、「知识 Wiki 里也没有查到目标（GOAL）或项目（PROJECT）类的页面」（搜了 3 次）。

## 查到的
- **4 的原因**：`search_wiki`（`WikiToolAgent`，网页的 AI 助手、命令行、`zhiqu mcp` 用的都是它）只拿关键词去匹配标题 + 摘要 + 正文，**不看页面类型**。
  模型按「目标」「GOAL」「项目」去搜，一页标题叫「27考研」、正文里没写「目标」两个字的目标页就找不到；也没有「列出某一类的全部页面」的办法。
  代码工作区的提示词里还写着「出题之前先 search_wiki 看看『薄弱点』类的页」—— 这件事一直做不到。另外：匹配是整串子串（「27 考研」中间多一个空格就不中）；只返回前 12 条、不说一共几条。
- **2**：桌面应用的 WKWebView 不显示原生的 `title` 提示（浏览器里显示，但要停一秒多）。全站有不少只靠 `title` 说明的地方（收起的侧栏、两侧面板的开关、截断的名字）。
- **1**：面板右上角的收起按钮是绝对定位的；第四十四轮去掉了它的白底，原来被白底盖住的那半个字露了出来 —— 其实一直是叠着的。
- **3**：首页轮播的四张图是 10 月 4 日（第二十六轮）截的，还是改版之前的样子（彩色主题、Unicode 符号、带头像的气泡）。

## 计划
1. **`search_wiki` 认页面类型**：关键词也匹配页面类型（代码和中文名：GOAL / 目标、PROJECT / 计划 ……，老的 SCHEDULE、REMINDER、MATERIAL 归到对应的中文名）；
   加一个可选的 `type` 参数（代码或中文名都认，认不出就照实说可用的有哪些）；只给类型、不给关键词 = 列出这一类的全部页面；关键词按空格拆开、每个都要中；
   结果里带一共几条，没列全时说一声。类型的中文名收成一处（原来 `KnowledgeServiceImpl` 里有一份）。工具说明、提示词、命令行和服务端的「正在查……」一起改。
2. **悬停提示**：自己画一个小提示（`zhiqu-ui.js`，全站）：鼠标停在带 `title` 的元素上 0.4 秒出（刚出过一个时立即出），在它下面、放不下就上面；收起的侧栏和面板竖条上的出在旁边；
   移开、点下、滚动、按键就收；键盘走到上面时也出。原生的那个要让开：停上去时把 `title` 挪到 `data-zq-tip`（之后代码再写 `title` 也认）；只有图标、没有 `aria-label` 的顺手补上。触屏不出。
3. **面板头上给收起按钮让位**：展开的面板第一行右边留出按钮的位置（样式表一处，不再各页各自 `margin-right`）。
4. **首页轮播**：换成新界面的截图。高清截图要么让截图工具在屏幕上开一个窗口（用户说过不要弹窗口），要么下载一个不带界面的浏览器 —— **问用户**。
   问过了（2026-10-06）：「截图要换，轮播样式也改」；截图「开一个窗口截」。这一件放到第四十六轮，这一轮只做上面三件。
5. **判据**：`search_wiki` 的行为（单元测试：按类型、中文名、只给类型、拆词、总数、认不出的类型）；提示（在 node 里真跑 `zhiqu-ui.js`）；面板头让位。扰动见红。
6. 真浏览器：悬停出提示、Wiki 目录头不叠；用本机假模型确认 `search_wiki` 按类型能列出来。全量、桌面应用重新打包。

## 结果（2026-10-08）

上面三件照计划做完；首页轮播问过用户，放到第四十六轮。

- **`search_wiki` 认页面类型**：新的 `com.zhiqu.common.WikiPageTypes` 是类型中文名的唯一出处（`KnowledgeServiceImpl` 原来那份改成调它）：
  目标 = GOAL、计划 = PROJECT / SCHEDULE、偏好 = PREFERENCE / REMINDER、薄弱点、资料 = RESOURCE / MATERIAL、对话摘要、日志、规则、备注 = NOTE（认不出的、没写的、index 都算备注）；
  `parse` 认代码（大小写不论）和中文名，「项目」算计划、「笔记」算备注，认不出返回 null。
  `search_wiki`：关键词按空格拆开、每个都要中，匹配标题、摘要、正文**和页面类型（代码和中文名）**；新参数 `type` 只看那一类（认不出就照实说可用的有哪些，不悄悄当成「备注」）；
  `query` 不再必填 —— 只给 `type` = 列出那一类的全部页面；一次最多列 20 页，结果里带 `total`，没列全时多一句 `note`。工具说明直接教模型：「我有哪些目标 / 计划」就 type 填那一类、query 留空。
  网页的 AI 助手、命令行、`zhiqu mcp` 用的都是这一个工具（命令行和 MCP 从 `/api/harness/tools` 取说明、经 `HarnessRemoteTools` 转给它），所以一处改全有。
  「正在查……」那一行（服务端 `CodeToolNarration`、命令行 `agent.js`）只给类型时说「查知识库里的目标页」（原来命令行会显示「查知识库「undefined」」）。
  用户自己那一页「27考研」没有去他的真实数据里看（不碰真实数据）：按他说的是一页目标页，单元测试里照样摆了一页「27考研」、类型 GOAL、正文里没有「目标」两个字 —— 原来的代码按「目标」「GOAL」都搜不到，现在搜得到、按类型列得出。
- **悬停提示**：`zhiqu-ui.js` 的 `setupTips`（全站）。鼠标停在带 `title` 的元素上 0.4 秒出（刚出过一个、接着停到旁边那个时立即出），在它下面、放不下就上面；收起的侧栏、面板竖条上的出在旁边；
  移开（挪到它里面的图标上不算）、点下、滚轮、滚动、按键、窗口失焦就收；键盘走到上面时立即出、焦点走了就收；触屏不出。停上去时把 `title` 挪到 `data-zq-tip`，浏览器自己的那个就不出了（不然两个）；
  之后代码再写 `title`（Wiki 目录的页数变了）也认。只有图标、没有名字的顺手补 `aria-label`。字已经整个摆在它上面的（展开的侧栏里「看板」两个字）不重复出，字被截断的照出。
  反色小签（`.zq-tip`：正文色底、页面底色字），`pointer-events:none`。`zhiqu-ui.css` 里原来那句「不自己造 tooltip，原生的在所有平台都对」改了 —— 桌面应用里原生的根本不出。
- **Wiki 目录头不叠字**：展开的面板第一行右边留 44px 给收起按钮（样式表一处 `[data-zq-collapse]>.zq-rail+*`）；AI 助手左面板「新建」按钮自己写的 `margin-right:26px` 去掉。量过：「203 页」右边缘 385、按钮左边缘 395。
