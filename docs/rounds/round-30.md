# 第三十轮（2026-10-04）：头像菜单 + 设置弹窗（方案第 4 步的第一块）

## 由来
用户 2026-10-04 的想法：「成就和统计之类的和个人中心，一起放到一个页面里 —— 点左下角头像向上弹出几个选项，点进去出现 Claude 那种弹窗」。
锐评之后用户定了：**做，统计留成页面**；**排在第 4 步（前端拆模块）的第一块**。

现状：侧栏里「个人中心」是一个长页面，塞着七样不相干的东西（头像与资料、提醒推送与渠道凭据、修改密码、命令行登录、账号与安全、
AI 模型配置、让 AI 读任务的开关）；「数据」组里只剩「专注统计」（成就第二十六轮收起来了）；「管理」组、界面风格也在侧栏里；
退出登录藏在个人中心的顶上。另外两处设计稿残留：个人资料卡的标题静态写着「王明远」，侧栏模板里头像字是「远」、名字是「王明远」、身份写死「管理员」
（启动时会被真值覆盖，没露出来）。

## 计划（开工时）

1. **侧栏只留干活的地方**：AI 助手、看板、任务、例行计划、参考计划、知识 Wiki。底部是头像按钮（头像、昵称、身份），去掉「个人中心」项、
   「数据」组、「管理」组和界面风格那一块 —— 它们都进头像菜单。
2. **头像菜单**（点头像向上弹出，Claude 那样）：顶上是昵称和用户名；设置、成就、专注统计（页面）、界面风格（原来那个弹层）、
   管理员多一组（监管后台 / 账号管理 / 反馈管理 / 共享计划审核）、退出登录。Esc、点外面关。
3. **设置弹窗**（Claude 那样：左边分栏、右边内容）：个人资料（头像、昵称、单位 / 学校、部门 / 职位、邮箱）、AI 模型（模型列表与新增、
   让 AI 读我的任务）、提醒（推送开关与渠道）、命令行（设备码登录、令牌）、账号与安全（修改密码、最近登录、退出登录）。
   **带地址**：`#settings/models` 这样的 hash 打开对应那一栏，刷新、直达、浏览器后退都对；关掉弹窗去掉 hash。
4. **第一个 ES 模块**：设置和成就的代码（个人资料、模型配置、提醒渠道、命令行登录、账号安全、成就列表，约 450 行）从 `zhiqu-api.js`
   挪进 `assets/settings.js`（原生 ES 模块，第一次打开弹窗时 `import()` 动态加载，平时不加载）。壳给它一个小的共享层
   （`window.zqShared`：请求、提示、转义、弹窗、当前用户……），这就是第 4 步之后每个页面模块要用的那一层。挪，不重写。
5. **成就**：弹窗（`#achievements`），和设置同一个模块。
6. **旧地址照常能用**：`profile.html`、`achievement.html` 换成跳转（到首页并打开对应弹窗）；命令行设备码登录的链接
   `profile.html#harness=XXXX-XXXX` 跳到 `#settings/cli` 并填好码 —— 服务器给的链接也改成新的，旧的照样能用。页面里指到 `profile.html` 的
   几处（AI 助手「去配置模型」、看板「提醒发不出去」）改成打开弹窗。
7. **判据**：模块能被 node 直接 import（hash 解析、分栏表这类纯函数直接测，不再从源码里抠）；壳的接线（侧栏没有了那几项、头像菜单有、
   管理员才有后台组、旧页跳转）；原来钉着 `profile.html` 结构的判据跟着搬；demo 残留（「王明远」「远」「管理员」）一起清掉。

### 怎么验
真浏览器：普通用户、管理员各一遍 —— 点头像看菜单；设置五栏逐个打开、改资料保存、加一个模型、开关读任务、刷新留在同一栏、后退关弹窗；
成就弹窗；旧地址 `profile.html#harness=…` 跳过去并填好码；手机宽度下菜单和弹窗。全量通过、扰动见红；桌面应用重新打包。

## 结果（2026-10-04）

照计划做完。

- **侧栏**只剩干活的六项（AI 助手、看板、任务、例行计划、参考计划、知识 Wiki）。底部的头像是个按钮，名字和身份等 `/auth/info` 回来再填 ——
  原来模板里写着设计稿的「远 / 王明远 / 管理员」，每次打开先闪一下。在专注统计或后台页时侧栏里没有高亮项，就让头像按钮亮着。
- **头像菜单**（`zhiqu-ui.js` 的 `openUserMenu`）：顶上昵称和用户名；设置、成就、专注统计、界面风格（右边写着当前的风格和深浅，点开是原来那个弹层）、
  管理员多一组后台、退出登录。Esc / 点外面关，↑↓ 能走。后台那一组按服务端角色画：本地存的角色是 ADMIN 而服务端说不是时不画（`setAdminNav` 校正）。
  收起的窄侧栏（手机上默认就是）里菜单从头像右边出来。
- **设置弹窗**（Claude 那样左边分栏、右边内容；高度固定，换栏时不跳）：个人资料、AI 模型（含「让 AI 读我的任务」）、提醒、命令行、账号与安全（改密码、最近登录、退出）。
  跟着地址走：`#settings/<栏>`，刷新还在这一栏；点菜单进来的按后退就关，关掉时也是后退回去；直接带着 hash 打开的关掉时把 hash 抹掉；换栏只改地址、不加历史。
  手机上铺满屏幕，分栏变成顶上一排页签。
- **成就**：`#achievements` 弹窗，原来那一页的样子（四个数、筛选、卡片）。
- **第一个 ES 模块** `assets/settings.js`：个人资料、模型配置、提醒渠道、命令行登录、账号安全、成就的代码从 `zhiqu-api.js` **挪**过来
  （壳 6007 → 5686 行：挪走约 420 行，新加的地址路由、共用层、退出登录约 100 行）；第一次打开弹窗时才 `import()`，地址带上壳自己的 `?v=`（从 `document.currentScript` 取，不另写一份令牌），离线缓存里也有它。
  它只用壳给的 `zqShared`（请求、提示、弹窗、当前用户、提醒渠道的规矩……），查元素只在弹窗里。原来按位置找元素（「第 2 个 input」「含『基本资料』的 section」）
  的地方都换成了 id —— 模板就在同一个文件里。「这个渠道的凭据齐了没有」仍只有壳里一份（建任务的表单也用它）。
- **旧地址**：`profile.html` / `achievement.html` 只剩一个跳转页（书签、历史记录还指着它们），在登录检查之前跳到首页的弹窗；
  `profile.html#harness=xxxx-xxxx`（之前的命令行打印的链接）跳到「命令行」那一栏并填好码（转大写）。服务器给命令行的链接改成 `/ai-assistant.html#settings/cli?harness=…`。
