# 第六十轮（2026-10-13）：知趣命令行 agent 的 HumanEval 跑分

## 用户选择

评测知趣命令行 coding agent，使用现有 DeepSeek 模型，完整运行官方 HumanEval 的 164 道 Python 题。
用户启动本机知趣桌面服务；读取模型列表确认 DeepSeek 配置为 ID 1、`deepseek-v4-pro`。
默认模型为另一供应商，所以每次请求必须核对实际模型，禁止回退后混入结果。

## 计划与评测协议

- 固定官方 HumanEval 数据和验证器版本，记录提交与数据 SHA-256。
- 直接调用现有 `runTurn`、本地工具、系统提示与真实模型网关，每题独立文件目录和会话。
- 每题一次 agent episode，可以自行读写文件和运行自建 smoke tests；隐藏官方测试只在最终评分时执行。
- 只把题目原始 prompt 和入口函数交给 agent，不提供标准答案或隐藏测试；`solution.py` 保留官方前缀，补全实现。
- 禁用远程办公工具、MCP、个人说明与网页存档，避免评测读取或改写真实任务、Wiki 和会话。
- macOS 使用任务级 `sandbox-exec`，限制文件读写范围和网关出站请求；子命令继承限制。
- 每题最多 20 轮、300 秒，并发 2；每个槽的请求起始间隔至少 2400 毫秒（包括重试和跨题切换），合计目标每分钟 50 次请求。记录原始会话、代码、模型与工具调用、用量、时间和错误原因。
- 先用官方标准实现跑绿、明显错误实现跑红，确认评分器能判对错；真实调用校准发现限流后，保留无效校准记录，固定正式协议并在新目录完整运行，不重抽较好结果。
- 分母固定 164，报告函数实现通过率和无效运行；不冒称 SWE-bench 成绩或原始纯模型排行榜分数。

## 结果

评分器的标准答案 164/164 通过；明显错误实现由官方断言判失败。离线适配器协议测试 12 条通过，隐藏字段投影和请求节奏判据已做扰动见红；文件工具、Python 子命令和任务级隔离均实测通过。

首次校准运行发现网关每分钟 60 次限流：8 题完成，72 题网关失败，2 题在停止时中断，82 题尚未执行。

## 推送前 review（用户要求 review and push）

独立检查生成器、评分器与报告，修复了实际可复现的边界问题：

- 中断时直接杀 worker 的进程组会留下 `LocalTools` 单独创建的命令进程组。现在先 SIGTERM 通知 worker 中止工具，最多等 5 秒再强制清理事先记录的子命令组；真实 macOS 沙箱另补仅允许同沙箱进程间的 signal 权限。两个取消判据和沙箱内自我取消判据均用原行为跑出断言失败后修复。
- 原评分器把固定控制请求文件放在候选可写目录里，并复用目录。现在控制数据经 stdin 传递，每次检查分配独立临时目录，正常 / 错误 / 超时退出均清理评分进程组；7 个离线回归通过，对旧版对照为 8 个断言 Failures、0 Errors。
- 生成前拒绝放在沙箱可读目录里的隐藏题集，收紧评测源码的读取范围；当前 macOS 运行器明确仅接受本机 loopback 网关，远程地址在调用模型前拒绝。
- 模型流必须先提供并通过实际模型核对，才能处理工具调用与输出；省略 start 信息的流由协议错误终止，禁止无模型证据的成功记录。
- 报告生成器正式入库，支持相同 DeepSeek 全量协议的 v2 / v3；归档索引改用仓库相对路径。旧 6 个工具文件以不可执行的文本快照保存并核对原哈希。

当前可运行工具为 **v3**；**156/164（95.12%）仍属于修复前冻结 v2**，没有调用模型重跑、改写候选或重算能力分。原始 manifest、score 与证据指纹保持不变。
新评分器另用官方标准实现自测 164/164 通过，错误实现确实失败，文件读 / 写及 IP 网络隔离探针均通过；这是验证器回归，不是新增 agent 成绩。

最终检查：生成器 19 项离线回归、评分器 7 项离线回归、JDK17 下文档 / 源码清洁 / 密钥防护 7 项均通过，无跳过。
报告重建验证了原始成绩、v2 / v3 区分、前缀与其他协议失败、统计不一致拒绝及输出转义；真实浏览器重新加载后失败筛选仍为 8 题。
