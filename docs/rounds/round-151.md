# 第一百五十一轮（2026-11-17）：干活中途补充第 2 步 —— 终端里回车补充、Tab 排队

## 由来

[`docs/steer-plan.md`](../steer-plan.md) 第 2 步，用户 2026-11-17 定的键位：生成中回车 = 补充给这一轮，Tab = 排到下一轮（和 Codex 一样）。第一百五十轮把收件箱做进了循环，这一轮把终端接上。npm 0.2.6 用户自己发。

## 要做的

- **`ui.js`**：
  - 一轮在跑、调用方给了 `steerTo` 时，回车把这句交给 `steerTo`。同一批到达的几行（终端不支持括号粘贴时粘进来的）合成一句再交。
  - `/` 开头的命令照旧排队。交不进去（箱子关了，这一轮在收尾）也退回排队。
  - 输入框上方一行「↳ 补充（下一步送到）：…」；模型读到时 `steerDelivered` 把它收起，在输出里留一行「↳ 补充：…」。
  - 干活时的 Tab（`liveKey`，排在 `menuKey` 后面：菜单开着时 Tab 照旧是补全）把正在打的这句排到下一轮。空的 Tab 吞掉，不插制表符。
  - `reclaimSteers`：没读到的放到排队最前面，并且之后回车不再补给这一轮。
- **`cli.js` 的 `turn()`**：
  - 先建好这一轮的 `Inbox` 交给 `runTurn`（`runTurnBody` 认 `opts.inbox`）。不在循环里建，是因为等 MCP 启动那会儿打的字也要能补进来。
  - 挂上 `ui.steerTo` 和 `ctx.onSteer`；`finally` 里关箱、`reclaimSteers` —— 正常结束时没读到的就是下一句（用户定的：没赶上就接着发）。
  - `mcpStarted` 挪进 `try`，好让 `finally` 一定走到。
- **Ctrl+C**（`interruptHandler`）：先 `reclaimSteers` 再 `unqueue`，没读到的补充和排队的一起放回输入框（补充在前），不发。
- `/goal`、`/review` 不给 `steerTo`：回车还是原来的排队。
- `/help` 和 README 说了新的键位。版本 0.2.6。

## 顺手修的（原来就有）

真终端里跑 Ctrl+C 时看到：放回输入框的字，光标在**行首**，接着打的字跑到前面去。原因是 `ask()` 重画提示符用的是 `rl.prompt()`，不保留光标。暂存掉这一轮的改动后，同样能复现，所以是第十三轮「排队的放回输入框」起就有的。这一轮补充也走这条路，所以改成 `rl.prompt(true)`。

## 怎么验

- `test/steer-input.test.js` 12 条：迷你终端模拟器判屏幕，另外两条走 `cli.js` 的 `turn()` 真跑一轮（假模型，模型想的时候往终端里打字）。
- 第一次跑扰动时，「菜单开着时 Tab 是补全」那条在**基线上就红**：测试没给 `Ui` 命令清单，菜单根本不弹。修了测试的搭法，基线全绿后，13 处扰动重跑，各自见红：
  - 回车一律排队；
  - 不接 Tab、菜单让 Tab 先走；
  - 命令也补充；
  - 交不进去不排队；
  - Ctrl+C 不收回、收回后回车还补给这一轮；
  - `turn` 收尾不收回、不把箱子交给循环、不接 `onSteer`；
  - 同一批不合并；
  - 读到了不收起；
  - `ask` 不保留光标。
- `interrupt.test.js` 手写的假 ui 加了 `reclaimSteers`：处理器的约定变了。
- 真终端：Python `pty` 起真的 `zhiqu` + 假模型服务器（第一次调用想 3 秒、调 `read_file`）。
  - 干活中敲「只看第一行」：第二次请求最后一条就是补充，屏幕先「下一步送到」、读到后「↳ 补充：只看第一行」。
  - 敲完立刻 Ctrl+C：只发了 1 次请求，字回到输入框；修光标之前 Ctrl+U 删不掉它，修了之后能。
- 命令行全量 `npm test`：663 条，644 过、0 失败、19 跳过（bubblewrap，macOS 上本来就跳）。
- `npm pack --dry-run` 带上了 `src/steer.js`、版本 0.2.6；`check-release` 通过。

## 结果

命令行里能中途补充了，发了 0.2.6 就到用户手里。

**发布顺序**：`deploy-from-dev.sh` 会先查 npm 上有没有 `package.json` 写的那个版本，没有就拒绝部署（第一百二十六轮）。所以 0.2.6 发出去之前，服务器部署会被它挡住。
