# 第一百零二轮（2026-11-02）：Wiki 公式的实时渲染 —— 表格格子改完停在源码、编辑器里的公式等不到 KaTeX

## 由来
用户 2026-11-02 贴了两张截图：Wiki 里一张「写法 / 效果」的表，「效果」一列的 `$$\dfrac{a}{b}$$` 显示成灰色等宽的源码，点进一格是 `$$…$$` 原文 ——「右边没有实时渲染」。
在验证库里照着建了一页（真浏览器），复现出三处：
1. **格子改完（或只是点进去再出来）停在源码**：离开格子时那一格单独重画（`renderBlock`），没有再交给 KaTeX（表格整张画的时候有 `hydrate`，这一步漏了）—— 截图里的灰色等宽字就是公式没画时的样子。
2. **编辑器里的公式等不到 KaTeX**：KaTeX 是懒加载的，只有阅读视图 / 表格这类走 `renderMathIn` 的地方会去加载；编辑器里的公式（`MathWidget`）只看当时 `window.katex` 在不在，
   不在就画成原文，加载好以后也不重画（装饰的 `eq` 只比源码，一样就沿用旧的 DOM）。一页里先画到哪条路，就决定了哪边停在原文：Chromium 里是正文的 `$E=mc^2$` 没画、表格画了。
3. **一行里的 `$$…$$`**：阅读视图和表格认（画成公式），编辑器不认（块公式只认单独成行的 `$$`），同一句话两边不一样。

## 计划
1. 离开格子时那一格重画完照样 `hydrate`（和整张表一样）。
2. KaTeX 只有一个加载入口（`zhiqu-api.js` 的 `loadKatex()`，JS 和 CSS 都好了才算好；`renderMathIn` 也走它），编辑器拿到「好了没 / 去加载」两个钩子：
   文档里有公式而 KaTeX 还没好时去加载，好了发一个刷新，行内和块公式的装饰重算；`MathWidget` 记着画的时候 KaTeX 好没好，好坏不同就不沿用旧的 DOM。
3. 编辑器认一行里的 `$$…$$`（和 `renderMarkdown` 同一条：里面要像公式，`$5 和 $$10` 这种不算）：单独占一行的画成块（居中），夹在字里的画成行内；
   阅读 ↔ 原文的位置映射把它当一个整体（和阅读视图里的公式节点一样）。
4. 判据先红；真浏览器里点格子、改格子、刷新页面各看一遍，截图给用户。界面改了静态资源 → 换缓存令牌。

## 结果
- **格子**：离开一格时那一格重画完照样交给 KaTeX（`options.hydrate(cell)`）。真浏览器里点进「效果」一格再出来、改一格（`b` → `b+c`）按 Tab 走，画出来的都是公式；
  暴力测试：从第一格 Tab 九下穿过整张表、再来回点三格、Esc 出去，「效果」一列 4 格都是 KaTeX、没有一格停在等宽源码，原文只多了改的那个 `+c`。
- **KaTeX 一个入口**：`zhiqu-api.js` 的 `loadKatex()`（同时问只加载一次；JS 和 CSS 都到了才算好；失败说没好），`renderMathIn` 也走它；`katexReady()` / `loadKatex()` 经 zqShared 给页面模块。
  编辑器拿到 `options.math`：文档里有 `$` 而 KaTeX 没好时去加载，好了发 `mathRefresh`，块公式（StateField）和行内（ViewPlugin）的装饰重算；
  `MathWidget` 的 `eq` 带上「画时好没好」，不再沿用画成原文的 DOM。刷新页面（冷启动）以后正文里的 `$E=mc^2$`、`$t=t_0$`、`$I \neq I_0$` 都画出来了（原来是原文）。
- **一行里的 `$$…$$`**：编辑器认了（`displayMathRanges`，和 `renderMarkdown` 同一条：里面要像公式，`$$10$$`、`\$$` 不算），夹在字里画成行内、单独一行画成块；
  阅读 ↔ 原文的位置映射把它当一个整体。点公式时光标落在哪由 `skip` 带着（`$` 1、一行里的 `$$` 2、块公式 3）。
- 判据：`wiki-cm-check.js` 加 4 条（扫描、KaTeX 好了之后重画、接上的几处、加载入口的行为），「接入」那条加上 `options.math`；
  扰动 13 处全红（格子不 hydrate、`eq` 不比好坏、块公式 / 行内不认刷新、`mathReady` 不问壳、不画一行里的 `$$`、`$$10$$` 也算、映射不认 `$$`、
  没 CSS 就算好、同时问加载两次、等着的不画、壳不给 `math`、编辑器不装加载那一块）+ 新的 `skip` 值 1 处红。
  `WikiEditingFeelTest` 对源码的那条（点公式光标的位置）跟着改写法，理由不变。`PageModulesTest` 抓到加载那一块的方法名 `check(` 像在调壳里的函数，改名 `loadFor`。
