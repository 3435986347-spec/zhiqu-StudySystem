# 第七十八轮（2026-10-19）：界面打磨第 9 步（一）—— AI 助手的内联样式进样式表、棘轮

## 由来
`docs/ui-plan.md` 第 9 步「收尾」：手机宽、暗色各走一遍；内联样式从 817 处降到 100 以内；判据做成棘轮（内联样式数、不同字号数只许降不许升）。
第 8 步做完时还剩 297 处（HTML 的 `style=` + 模块 / 共用层 JS 里拼的），大头是 AI 助手（`ai-assistant.html` 38 + `pages/ai-assistant.js` 83 = 121）和知识 Wiki（22 + 75 = 97）。
一轮做不完，分两轮：这一轮 AI 助手 + 立棘轮，下一轮 Wiki、看板、共用层，降到 100 以内、收口第 9 步。

## 现在是什么样
- 字号：样式表和内联里一共有 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 15 / 15.5 / 16 / 17 / 19 / 20 / 24 / 30 / 38 px 十几种写死的值，令牌只有 12 / 13 / 14 / 15 / 18 / 20 / 26。
- AI 助手：两侧面板的标题、小字、按钮尺寸都是内联；代码工作区的设置弹窗按下的档位靠 JS 改 `background / color / borderColor`；文件夹选择器悬停靠 `onmouseenter` 改背景；文件树用 📁 📄 当图标（`IconSetTest` 没认出 emoji）。
- 有判据按内联的字面认东西：手机段的 `[style*="calc(100vh - 110px)"]`、`PageHeadTest` 认面板 `<aside ... style="...background:var(--zq-bg)">`、`panel-motion-check.js` 的 218px / 262px。挪的时候和判据一起挪（CLAUDE.md 判据纪律第 7 条）。

## 计划
1. 棘轮先立（`InlineStyleRatchetTest`）：内联样式总数 `== N`（降了就把 N 改小、升了就红），不同的写死字号是一个固定的集合（多一种就红）。
2. `ai-assistant.html` 的内联样式全部进样式表（`.zq-ai-*`）；定高容器换成类，手机段那条跟着从 `[style*=…]` 换成类；`PageHeadTest`、`MobileLayoutTest` 的对应判据改成认类。
3. `pages/ai-assistant.js`：空状态、资料本卡片、来源、执行轨迹、差异视图、代码工作区（设置弹窗、文件夹选择器、文件树、搜索）、文件预览的内联样式进样式表；按下的档位用 `aria-pressed`，悬停用 `:hover`；📁 📄 换 `ICONS`。只留数据（颜色 / 进度这类按值变的，用 `--x` 变量）。
4. 字号收到令牌上：12.5 → 13（sm）、11.5 → 12（xs）；10 / 10.5 / 11（面板里的元信息、差异行）收成一个新令牌 `--zq-fs-2xs: 11px`（12 在 218px 宽的面板里换行变多；这个令牌是新加的，用户不同意就改回 12）。
5. 手机宽 / 暗色把 AI 助手走一遍（375 / 1440，浅 / 深，面板展开 / 收起），看到的问题当场修。
6. 判据见红（扰动）、真浏览器暴力（面板开合、工作区设置、长路径、超长文件名、深色下各状态的对比度）、全量、换缓存令牌、截图。

## 结果
**样子挪进样式表**
- `ai-assistant.html` 38 → 0、`pages/ai-assistant.js` 83 → 1（资料卡片的类型色 `--srcc`，是数据）；JS 里改样子的地方 13 → 3（输入框按内容长高的 `style.height`）。全站内联样式 297 → 176。
- 两页（AI 助手、知识 Wiki）的定高包裹是同一个类 `.zq-fill-page`；手机段那条从 `[style*="calc(100vh - 110px)"]{…!important}` 换成 `.zq-main>.zq-fill-page{…}`。
- 两侧面板展开的宽度（218 / 262）写在 `.zq-ai-side` 上，`setupPanels` 照旧读算出来的 `flex-basis`。
- 颜色看数据：执行轨迹的一步、叙述、消息的出错 / 不完整提示、资料的状态点都是 `data-state`；选中的 Notebook 是 `aria-current="true"`；代码改动的差异行是 `data-op="add|del|same"`。
- 代码工作区：设置里按下的档位原来是 JS 改 `background / color / borderColor`，现在是 `aria-pressed`（四个档位成组、有名字）；选文件夹的一项原来是没有 `href` 的 `<a>`、悬停靠 `onmouseenter` 改底色 —— 键盘 Tab 不到，现在是按钮、悬停在样式表；「上一层」到顶时灰掉不再靠 JS 改 `opacity`；文件树、路径、选文件夹里的 📁 📄 换成 `ICONS` 新加的 `folder` / `file`。

**字号收到令牌上**：AI 助手（和它用到的资料卡片、产物、计划确认弹窗）里 12.5 → 13（sm）、11.5 → 12（xs）、10 / 10.5 / 11 → 新令牌 `--zq-fs-2xs: 11px`。
改前改后同一个账号逐块量（`r78-geo.js`）：1440 / 375、浅 / 深，骨架（包裹、工作区、两侧面板、对话区、输入框）的位置大小一个像素都没变；变的只有这几处字号，右边执行轨迹因为元信息 10 → 11px 长了 17px。
`--zq-fs-2xs` 是这一轮新加的：12px 放进 218 宽的面板，元信息换行变多；用户要是觉得一种字号都不该加，改回 12 就是改这一个令牌。

**手机 / 暗色走一遍时看到的**：资料卡片左上角的类型（「文本文件」）被底下的信息栏盖住 —— 改前手机上盖一半、桌面上 93px 的格子里本来就叠着；这一轮元信息 10 → 11px 以后桌面上整个被盖住。
原因是类型和信息栏都绝对定位、卡片 `overflow:hidden` 钉成正方形，两行名字 + 两行状态放不下就叠上去、裁掉。现在两个都在文档流里（`flex:none`），`aspect-ratio:1/1` 只是下限：
内容多了卡片长高（93 → 128px）。`min-height:92px` 也去掉了 —— 写了定值，`aspect-ratio` 按内容撑高的那一条就不算（量出来过）。类型右边原来给下载按钮留 34px，四个字放不下（「文本…」），按钮只在悬停时出现、自己有底，改成留 10px。

**手机上的一处变化**：「上传资料 / 添加 URL」原来是内联的 `1fr 1fr`，被手机段按 `style` 压成一上一下；挪进类以后两个按钮并排（面板浮在对话上、宽 251 / 202，放得下）。

**棘轮**（`InlineStyleRatchetTest`）：每个文件的 `style=`、JS 里改样子的地方用 `==` 钉着（少了要把数改小）；写死的字号是 20 种的一个集合（`.92em`、10 ~ 38px），多一种就红。这一轮 AI 助手的那几种字号别的页还在用，种数没少 —— 下一轮收 Wiki、看板时少。

**挪内联会让认字面的判据白绿**（CLAUDE.md 判据纪律第 7 条），这一轮改了的：
- `diff-check.js` 数 `<div style="display:flex` 来判「没有把 200 行全渲染」—— 挪走之后恒为 0，`< 30` 永远成立；改成数 `.zq-diff-row`、要求 `> 0 && < 30`。颜色从「HTML 里有 `--zq-bad`」改成认行上的 `data-op`，样式表那一半在 `CodeDiffJudgmentTest`。
- `TallPanelsTest` 只扫页面里的 `max-height`，挪走之后自动变绿；改成连样式表里 AI 助手的规则一起扫（下限 20 条）。
- `PageHeadTest`（面板的底色、工作区不是卡片）、`AiComposerTest`（对话栏是定位容器）、`MobileLayoutTest`（定高容器、网格的下限 4 → 3）、`DesignTokensTest`（内联字重的下限 28 → 14）改成读类和样式表。
