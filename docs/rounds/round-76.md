# 第七十六轮（2026-10-19）：图标的 1024 母版和矢量稿

## 由来
第七十四轮用户说「最新的图标在 downloads 里」；这一轮用户把两个压缩包传了上来（`知字图标设计方案` 的两次导出）。
第七十二轮收口时问过用户：设计稿有没有 1024 或矢量版 —— macOS 图标最大那一档（512@2x，1024 像素）只能从 512 放大。

## 查出来的
- 两个包里的 PNG（`favicon-16/32`、`icon-192`、`icon-512`、`icon-512-maskable`、`apple-touch-icon`）**和仓库里现在用的逐字节一样**：第七十二轮换上的就是这一套，网页的图标不用动。
- 第二个包多了两样：`icon-1024.png`（1024 × 1024）和 `icon.svg`（`viewBox 0 0 100 100`：`#18181B` 圆角方块 + 一道白色螺旋线，没有脚本、没有外链，带一段内容来源的元数据）。
- `icon-1024.png` 缩到一半和网页上的 `icon-512.png` 逐像素比，平均每个通道差 0.48 / 255 —— 是同一张图的高清版，不是新设计。
- 矢量稿用在小尺寸上不合适：线宽是画布的 0.45%，16 / 32 像素时不到十分之一像素，所以设计稿给小尺寸专门出了两张 PNG。它适合做母版留档。

## 计划
1. `icon-1024.png`、`icon.svg` 原样放进 `deploy/desktop/icon/`（母版，和第七十二轮放进去的 `favicon-16/32` 在一起）。
2. `MakeIcon.swift` 改读 1024 母版：iconset 最大那一档不再放大，别的档都从 1024 缩；检查尺寸的那一句跟着改。打包脚本传 1024 那张。
3. 两个 ICO（`favicon.ico`、`zhiqu.ico`）是 `MakeIcon` 在 Mac 上生成、手动拷回仓库的：这台是 Linux，没有 `swiftc`，这一轮不重出（48 以上那几档从 1024 缩和从 512 缩差别很小），下次在 Mac 上打包时照注释重出。
4. 判据（`WebAppManifestTest`）：1024 母版是真的 1024 × 1024 PNG、缩一半和网页的 512 是同一张图；矢量稿是 SVG、没有脚本和外链；打包脚本把 1024 那张交给 `MakeIcon`、`MakeIcon` 认 1024。扰动见红。
5. 界面里的「知」字标识（侧栏、落地页）换不换成螺旋线 —— 第七十二轮问过、还没定，接着问。
6. 收口：全量、记录、提交推送。桌面应用要在 Mac 上重新打包，新的 `.icns` 才到用户手里。

## 结果
- `deploy/desktop/icon/` 多了两份设计稿原样（逐字节就是包里那两个）：`icon-1024.png`、`icon.svg`。网页的四张图标、两个 ICO、`favicon-16/32` 都没动（和包里的一样）。
- `MakeIcon.swift` 的母版换成 1024（检查尺寸的那一句、用法、注释跟着改），打包脚本把 `deploy/desktop/icon/icon-1024.png` 交给它：macOS 图标的十档都从 1024 缩，最大那一档不再放大。
  这台是 Linux、没有 `swiftc`，`MakeIcon` 这一轮没编译过：改的只是一个数和几行字，下次在 Mac 上打包时会编一次（打包脚本每次现编）。
- **判据**（`WebAppManifestTest` 加两条）：母版是 1024 × 1024、缩一半和网页的 `icon-512.png` 平均差不到 2 / 255（实测 0.48）、打包脚本传的是它、`MakeIcon` 认 1024；
  矢量稿是那张 100 × 100 画布的 SVG、底是 `#18181B` 圆角方块（母版的底色实测也是它，四角透明）、没有脚本 / 事件 / 外链。
  扰动 8 处、8 / 8 见红：打包又拿 512、`MakeIcon` 认 512、1024 的位置放 512、换成左右翻过来的同尺寸图、矢量稿里加脚本 / 换底色 / 挂事件 / 引外链。
- **判据照不出来的**：把 512 放大成 1024 放进来，「缩一半和 512 一样」照样成立 —— 而放大正是这一轮要去掉的。试了两种量法（每个 2 × 2 小块里的细节、离 512 插值的距离），
  真 1024 和放大出来的只差 1.24 对 1.04、1.56 对 1.24，分不开，就没写成判据；母版是设计稿原样这一点靠记录（这一轮放进去的就是用户包里的那张）。

## 收口
- 后端全量 `mvn -o clean test`（开着 Docker）：**1267 条、0 失败、跳过 9 条**（只在 macOS 上跑的桌面应用判据）。
- 静态资源没动，不用换缓存令牌；网页的图标本来就是这一套。
- **要在 Mac 上做的**：重新打包桌面应用，新的 `.icns` 才到用户手里（顺带 `MakeIcon` 会编一次）；两个 ICO 要不要从 1024 重出也在那时候定（48 以上几档会稍微清楚一点）。
- **还要用户定的**（第七十二轮问过）：界面里的「知」字标识（侧栏左上角、落地页）换不换成螺旋线。矢量稿可以做这个，但线宽只有画布的 0.45%，侧栏那么小（24 像素）时线条只剩一层灰 —— 要换的话得给小尺寸单独出一版。
