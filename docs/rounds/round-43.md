# 第四十三轮（2026-10-06）：界面打磨第 3 步 —— 侧栏、页面头部；AI 助手一种底色

## 由来
`docs/ui-plan.md` 第 3 步（外壳）。第四十二轮做到一半用户说：「在 ai 助手那里，底色和展开旁边的颜色不要区分会不会更好」—— 一起做。做完给用户截图（他说的「第 3 步做完给截图」）。

## 计划

1. **AI 助手一种底色**（用户说的）：现在是三层颜色 —— 页面底色上放一张白卡片（描边 + 阴影），卡片里的头部条和两侧面板是浅灰（`card-soft`），对话区是白的。
   改成：卡片、头部条、两侧面板（含收起后的竖条）、对话区都用页面底色（`--zq-bg`），只靠细线分隔；去掉卡片的描边和阴影。
   手机上展开的面板浮在对话区上面，要不透明 —— 也是 `--zq-bg`。头部条里重复的「AI 助手」去掉（页面标题已经写了）。
2. **页面头部一种写法**：`.zq-page-head`（标题 + 可选一行说明在左、操作在右，窄了换行）。去掉标题上面那行小字（「今日行动台」「任务中心」「长期节奏」「计划库」「数据洞察」「管理员」）——
   侧栏已经亮着在哪一页了；去掉和侧栏重复的「返回看板」「回到看板」。说明那一行用 `.zq-page-sub`。11 个页面一样写，不再各写各的内联样式。
   看板拿 `header span` 的第一个写日期 —— 说明那一行要还是头部里的第一个 `span`。
3. **侧栏**：「收起」不再是导航最上面一整条带字的按钮，改成品牌那一行右边的一个小图标按钮（像 Claude）；收起后图标在品牌标志下面。导航项悬停 / 选中 / 键盘焦点三种状态。
4. **判据**：每个页面头部都是 `.zq-page-head`、没有内联样式、没有小字标题；AI 助手的卡片、头部条、两侧面板都是页面底色（不是 `card` / `card-soft`）、卡片没有阴影；
   收起按钮在品牌那一行里。各自扰动见红。
5. 截图（浅 / 深：看板、AI 助手、任务、Wiki、例行计划、参考计划、收起后的侧栏、手机宽）发给用户；桌面应用重新打包。

### 怎么验

## 结果（2026-10-06）

照计划做完。

- **AI 助手一种底色**：外层的白卡片（描边 + 圆角 + 阴影）去掉，工作区只在顶上留一条细线；两侧面板（展开、收起的竖条）都是页面底色 `--zq-bg`，对话区透明；
  卡片头部那条浅灰的条整条去掉 —— 重复的「AI 助手」删了，「当前 Notebook」挪到页面标题下面当说明那一行（名字长时省略号，悬停看全名照旧），同步状态挪到头部右边。
  两侧面板的收起 / 展开按钮去掉白底和描边，只剩图标（悬停有浅底）。手机上展开的面板浮在对话区上面，底色不透明（量过：`rgb(250,250,250)`、`position:absolute`）。
  量过：浅色时页面、工作区、两侧面板都是 `rgb(250,250,250)`，工作区没有阴影。
- **页面头部一种写法**：11 个页面都是 `<header class="zq-page-head">`：左边 `h1.zq-h1` + 可选一行 `.zq-page-sub`（次要文字色），右边 `.zq-page-actions`；放不下就换行。
  去掉标题上面那行小字（今日行动台、任务中心、长期节奏、计划库、数据洞察、四个后台页的「管理员」）和任务页、例行计划页的「返回看板」「回到看板」。
  Wiki 头部的按钮从 30px / 12.5px 回到默认的 32px / 13px（和别的页一样）。看板的日期原来写进「头部里第一个 `span`」，改成按类找 `.zq-page-sub`。
  卡片里的小标题（「本周日历」「象限摘要」……）不在这一步，留给第 5 步以后各页自己的那一轮。
- **侧栏**：收起按钮是品牌那一行右边的 28px 图标按钮（`aria-label` 跟着收起 / 展开换）；收起后（56px 宽）品牌标志和按钮上下排。导航项、收起按钮在键盘焦点上有焦点环。
  量过：品牌标志和按钮的竖直中线对齐（都是 34px）。

**判据**：新的 `PageHeadTest` 四条（页面头部一种写法 —— 只扫操作那一侧以外有没有内联样式；头部的样式定义一次、会换行、看板的日期写在说明那一行；
AI 助手一种底色；侧栏的样式）；`ui-shell-check.js` 加六条（在 node 里真跑 `zhiqu-ui.js`：收起按钮在品牌那一行里、整个侧栏只有一个、只有图标没有字、
展开 / 收起时 `aria-label` 各是什么）。写的时候删掉了一条「标记里有 aria-label」—— 启动时 `applySideCollapsed` 总会写上，这条照不出真的错，「展开着叫什么」那条已经管住了。
