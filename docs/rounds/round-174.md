## 要做什么

上一轮的产物把 `.tmp-multiturn.js` 这类验证脚本跑完就 `delete_file` 进了回收站，用户没有可以重跑的测试。系统提示还写着「校验脚本用完删掉」。

- `.tmp-*.js` / `.mjs` / `.cjs`：`delete_file` 和补丁里的删除都不放行，直到 `tests/<名字>.test.js` 或 `test/<名字>.test.js` 引用了 `node:test` 或 `node:assert`，并且至少 40 字。
- 只有 `node --check`、空文件、太短的 `assert(1)`、写了一长串 `assert.equal` 但没引用那两个模块，都不算收成。
- 一次性预览页（`.tmp-*.html`）和普通文件（`check.js`）照旧能删。
- 系统提示改成：验证脚本要留下，收成测试再删临时副本。
