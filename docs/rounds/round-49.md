# 第四十九轮（2026-10-09）：迷你番茄钟第 1 步 —— 番茄钟的状态存下来、全站共用

## 由来
`docs/mini-pomodoro-plan.md`，用户 2026-10-09 定了：只做 macOS 桌面应用、番茄钟卡片上「缩小到桌面」、迷你窗是半透明的深色胶囊、放倒计时 / 开始暂停 / 关联的任务名 / 今天第几轮。
步骤三步（每步一轮），这是第 1 步：迷你窗和主窗口要看到同一个钟，前提是番茄钟不再只活在看板那一页的内存里。
同一天用户还定了「首页轮播里看板那张现在就重出」（第四十八轮看板改版之后），截图已经重出，随这一轮提交。

## 现在是什么样
- 番茄钟是看板页的一段内联脚本，计时的状态（结束时刻、时长、关联任务）在那一页的闭包里：
  在看板上开始一个番茄钟，切到 AI 助手页，它就没了 —— 不记这一次专注，到点也没有提醒；回到看板是「25:00 待开始」。
- 开着两个看板标签页，各算各的：一个开始了，另一个不知道。
- 到点时记一次（`recordPomodoro`，先存设备再发，断网补记）、响一声 + 通知、标签页标题挂「✓ 专注结束」；钟往回拨时结束时刻跟着往回挪（第二十一轮）。

## 计划
1. **状态存在 localStorage**（`zq.pomo.<用户 id>`，按人分开）：一次专注一个 id；在跑的记结束时刻，暂停的记还剩几秒，带关联任务的 id 和名字（迷你窗要显示）。
   计时照旧按结束时刻算（后台标签页、合上笔记本不停）。主动退出时删掉（和草稿一样：任务名不留在公用电脑上）；登录过期不删。
2. **计时挪进壳**（`zhiqu-api.js`，和待补记放在一起）：每一页登录后都看着这个钟 —— 一秒一跳、别的标签页改了马上跟上（`storage` 事件）、切回来马上刷一次。
   看板的卡片改成页面模块里的一段（`pages/dashboard.js`），只管画和按钮，开始 / 暂停 / 重置 / 换任务都交给壳。看板那段内联脚本删掉（`InitErrorReplacesDemoContentTest` 给它开的口子一起收掉）。
3. **到点只记一次、只提醒一次**：哪一页先看到到点，就在浏览器的锁（Web Locks）里「看一眼还是不是在跑的那一个 → 标成做完」，只有标成功的那一页记录、提醒；
   记录的幂等键就是这次专注的 id —— 万一两页都记了（没有 Web Locks 的浏览器），服务端也只记一份。别的标签页看到「做完了」只在标题上挂「✓ 专注结束」。
4. **一页都没开着的时候到点了**（关了浏览器、合了盖子）：下次打开任何一页时补上 —— 记到结束的那一天（跨了天就带上那天）；过了 15 分钟才发现的不响、不弹，只说一句。
   这是一个取舍：关掉页面不再等于放弃这一次专注，要放弃按「重置」。
5. **钟往回拨**：用这一页的单调时钟（`performance.now()`）算「本该是几点」，比真钟快出 1.5 秒以上就把结束时刻往回挪；在锁里只挪「自己上一跳以来没人写过」的那一份 —— 两个标签页不会各挪一遍。
6. **任何一页都看得到**：侧栏用户头像上面一行「专注中 18:42」/「已暂停 18:42」，点了去看板；收起的侧栏只有图标和时间；看板本页不显示（卡片就在那）。
7. **判据**：新的 `pomo-shared-check.js` 在 node 里真跑壳里的这一段（两个「标签页」共用一份存储、一把锁）：开始 / 暂停 / 继续 / 重置；换一页还在；到点只记一次、只提醒一次、幂等键是 id；
   别的标签页只挂标题；关着的时候到点补记到那一天、不响；钟往回拨挪一次、两页不挪两遍；别的账号的看不见；退出删掉。原来钉在看板内联脚本上的几条判据挪到新的位置。扰动见红。
8. 首页轮播的看板截图换成第四十八轮之后的（已经重出）；缓存令牌换；真浏览器暴力测试（两个标签页、连点开始暂停、到点时两页都开着、切页）；截图给用户；全量；桌面应用重新打包。

## 结果（2026-10-09）

照计划做完；真浏览器里另外照出一处补记的 bug，一起修了。

- **钟挪进了壳**（`zhiqu-api.js`「番茄钟：全站共用一个钟」那一段）：状态存 `zq.pomo.<用户 id>`，`watchPomo()` 每一页登录之后一秒一跳、`storage` 事件马上跟上、切回来马上刷；
  所有改动走 `changePomo(fn)`：Web Locks `zq-pomodoro` 里「读 → 看还是不是那一个 → 写」，`rev` 每写一次加一。存不进 localStorage 时这一页自己记着（照样能用，和原来一样只活在这一页）。
- **看板的卡片**（`pages/dashboard.js` 的 `wirePomo` / `drawPomo`）只画、只把按钮交给壳；看板一启动先接卡片（在任何请求之前），重新取几遍按钮只接一次。
  在跑 / 暂停着时时长锁住（锁住的输入框第一次有了样子：变灰、光标不能点）；下拉框跟着那一个钟的任务，任务不在列表里就补一项；人正在选的时候不拨回去。
  `dashboard.html` 那段内联脚本删了，`InitErrorReplacesDemoContentTest` 给它开的口子收掉 —— 现在页面里只许有主题那一行内联脚本。
- **到点**：哪一页先看到就在锁里标「做完」，只有它记录（幂等键 = 这次专注的 id）和响 / 弹通知；每一页的标题都挂「✓ 专注结束」；记上之后别的页（看板）刷新今天的个数。
- **关着的时候到点了**：下次打开哪一页都补上，记到结束那天（跨了天就带上那天），过了 15 分钟才发现的不响不弹，只说「番茄钟在 03:13 到点了（那时一页都没开着），记进那天的专注时长」。
- **钟往回拨**：按这一页的 `performance.now()` 算本该是几点，慢出 1.5 秒以上就把结束时刻往回挪；只挪自己上一跳看到的那一份（`rev` 对得上），两页同一刻或者一前一后看到都只挪一遍。
- **侧栏**：头像上面一行「专注中 18:42」/「已暂停 18:42」（变灰），提示里带任务名，点了去看板；收起的侧栏只有计时图标和时间；看板本页不显示。新图标 `timer`。
- **退出时删掉**（和草稿一样，任务名不留在公用电脑上）。
- **修的 bug（真浏览器照出来的）：刚记的番茄钟被说成「补记了 1 个番茄钟（专注完的时候网断了）」**。关着页面时到点的番茄钟，打开页面那一刻「记它」和「打开页面的补记」撞在一起：
  补记那一趟原来和正在发的那一趟共用结果，把刚记的说成补记、两句提示叠在右上角。→ 补记先等正在发的那一趟发完，再看还剩什么（`pomo-outbox-check.js` 加一条，先见红）。
- 首页轮播里看板那张（浅 / 深）换成第四十八轮看板改版之后的（用户 2026-10-09「现在就出」）。

**判据**：新的 `PomodoroSharedTest` 三条 —— `pomo-shared-check.js` 28 条（两个「标签页」共用一份存储、一把锁，真跑壳里那一段）、`pomo-card-check.js` 12 条（真跑看板的 `wirePomo` / `drawPomo`）、接线；
`pomo-outbox-check.js` 加一条。原来钉在看板内联脚本上的五处（`FrontendClockTest`、`MainFlowWalkthroughTest`、`PageNotifyAndSharedLoginTest`、`PomodoroOutboxTest`、`InitErrorReplacesDemoContentTest`）挪到新的位置或交给 node 里的行为判据。
