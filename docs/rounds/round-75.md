# 第七十五轮（2026-10-18）：界面打磨第 8 步（三）—— 设置、成就弹窗

## 由来
`docs/ui-plan.md` 第 8 步「其余页面」原定分三轮，第三轮（设置 / 成就弹窗、后台四页、落地页）排在第五十九轮 —— 那一轮做了用户要的模型地址，之后一直没轮到。
这一段东西多，分两轮：这一轮设置和成就两个弹窗，下一轮后台四页和落地页。
（第七十四轮用户说「最新的图标在 downloads 里」：云端的会话读不到用户电脑上的文件，等用户传上来再换。）

## 现在是什么样（验证账号：两个模型配置、解锁了一个成就；Chromium 1440 × 900 / 375 × 812，浅 / 深）
- 打开设置（不管从哪一栏进），焦点落在第一栏「个人资料」上、带着焦点框 —— 进「AI 模型」时两栏都像选上了（手机上也是）。分栏不能用方向键换。
- AI 模型：卡片标题「本地 Ollama（我的）」，右边又是一个「我的」；Provider 那格写的是代码 `OPENAI_COMPATIBLE`、`OLLAMA`（下面的下拉写「OpenAI-compatible」「Ollama 本地模型」）；没存 Key 写「Key：—」。
  点「编辑」：显示名称框里是「本地 Ollama（我的）」（服务端存的时候会去掉，可用户看到的是要不要自己删掉那几个字）；表单看不出是在新建还是在改哪一个（只弹一下提示）；
  「新建模型」按钮的意思其实是「不改了、清空表单」。
- 成就：筛选按下的样子是 JS 改背景色；没解锁的卡写「进行中」，筛选里叫「未解锁」。
- 深色下打开的开关（「让 AI 读我的任务」）是白底配白钮，看不出开没开 —— JS 写死了白色的滑块，底色是主色（深色下主色是浅的）。
- 手机上（Windows 上的浏览器也是）弹窗右边漏一条没变暗的边（375 宽时 10px）：`html{scrollbar-gutter:stable}`（第六十五轮，锁滚动时正文不往右跳）留出来的槽，固定定位的遮罩不盖它。
- `assets/settings.js` 里 76 处内联样式；开关、提醒的三组渠道、状态的颜色都是 JS 改 `style`
  （提醒那三组是因为内联的 `display` 压过了 `hidden`，只能 JS 改 `style.display`）。

## 计划
1. 样子挪进样式表（`.zq-set-*`、`.zq-ach-*`、`.zq-switch`）：settings.js 不拼内联样式、不在 JS 里改样子；渠道三组用 `hidden`，状态的颜色用 `data-state`。
2. 开关 `.zq-switch`：`role="switch"` + `aria-checked`，滑块、打开的颜色、键盘焦点都在样式表。
3. 分栏照 tabs 的规矩：选中的那栏 `tabindex=0`、别的 `-1`，← → / ↑ ↓ / Home / End 换栏；打开时焦点落在选中的那一栏；面板 `aria-labelledby` 指向它。
4. AI 模型：卡片标题写名字本身；Provider 写人话（和下拉同一份表）；没存 Key 写「没有保存 Key」；
   表单上面一行标题：「添加模型」/「编辑：X」，编辑时按钮是「保存修改」+「取消编辑」，不编辑时只有「保存模型」；编辑时名字框里是名字本身。
5. 成就：筛选用 `.zq-seg` + `aria-pressed`；没解锁的写「未解锁」；卡片网格 `auto-fill`（窄了自己少列）。
6. 遮罩盖满整个视口，连滚动条的槽一起（`width:100vw`）。
7. 判据：`settings-check.js` 里真跑发布的模块（开关、分栏的键盘、模型卡片和表单标题、成就卡片和筛选）；静态的一半（没有内联样式、没有 `.style.`、开关 / 分段 / 遮罩的样式规则）；
   跟着改钉旧写法的判据（`MobileLayoutTest`「弹窗里的网格」、`InitErrorReplacesDemoContentTest` 的成就筛选、`AiReadTasksWiringTest`）。扰动见红。
8. 真浏览器：1440 / 375、浅 / 深的前后对比截图；暴力：连点开关、键盘鼠标来回换栏、编辑 / 取消编辑来回、成就筛选来回点。全量。

## 结果
1. **样子进样式表**：`settings.js` 的内联样式 76 → 0 处，也不再在 JS 里改 `style`（`SettingsLookTest`）。样式表里新的一段 `.zq-set-*` / `.zq-ach-*` / `.zq-switch`，字号都用字阶（原来夹着 10.5 / 11 / 11.5 / 12.5 / 13.5 / 14.5px）。
   提醒渠道的三组用 `hidden`（全局那条 `[hidden]{display:none !important}` 本来就压得过内联的 `display` —— 原来注释里「只能 JS 改 `style.display`」的理由不成立）。
2. **开关** `.zq-switch`：`role="switch"` + `aria-checked`；打开时滑块是「主色上的字」那个颜色 —— 深色下主色是浅的，原来白底配白钮。
3. **分栏**：选中的那栏 `tabindex=0`、带 `autofocus`（`openModal` 先找 `[autofocus]`），别的 `-1`；← → / ↑ ↓ 换栏（到头绕回去）、Home / End；
   换栏时焦点在分栏上就跟着过去（方向键、浏览器前进后退都是改地址换栏 —— 原来焦点框留在上一栏）；面板 `aria-labelledby` 跟着换。头像是按钮了（原来是 `div`，键盘换不了头像）。
4. **AI 模型**：卡片标题写名字本身、Provider 写人话（`MODEL_PROVIDERS` 一份表，表单的下拉也照它画、`value` 是接口里的代码）、没存 Key 写「没有保存 Key」、四格的颜色是 `data-state`；
   表单上面一行标题「添加模型」/「编辑：X」，编辑时「保存修改」+「取消编辑」，名字框里是名字本身；删掉正在编辑的那个模型时表单回到「添加模型」。
5. **成就**：筛选是 `.zq-seg` + `aria-pressed`；没解锁的写「未解锁」；卡片 `auto-fill`（1440 宽三张一行，手机一列）。
6. **遮罩** `width:100vw`：375 宽时原来右边漏 10px。
7. **判据**：`settings-check.js` 33 → 54 条（开关、分栏的键盘、模型卡片和表单标题、成就卡片、探测状态的颜色），`SettingsLookTest` 7 条（静态的一半）；
   `MobileLayoutTest`「弹窗里的网格」原来扫内联的 `grid-template-columns`，改成核对类和样式表（四种网格各自在手机上怎么排）；
   `DesignTokensTest` 内联字重用令牌的下限 45 → 35（这一轮挪走 13 处，现在 41 处）。扰动 18 处，18 / 18 见红。
8. **真浏览器**（Chromium，`zhiqu_verify` 库）：暴力 23 / 23 —— 从「AI 模型」进来焦点在它上面；乱按 23 下方向键之后选中、焦点、地址、面板、标签对得上；地址换栏焦点跟着；
   连点开关 9 次和服务端一致；深色下打开的开关滑块和底色不一样；编辑 / 取消编辑来回 12 次停在「添加模型」；改着 A 点 B 的编辑表单换成 B；保存连点两下不多建、名字里没有「（我的）」；
   没凭据开不了提醒、来回换渠道只露出一组；成就筛选乱点 30 次只按下最后那个、个数对；375 / 320 宽遮罩盖满、成就一列、不横着滚；没有抛错。
   对照组（改之前的静态文件、同一个后端）：能比的 10 项全红，到「编辑」那一步旧页面没有新元素，脚本停在那里。
   前后对比截图（1440 / 375、浅 / 深，五栏 + 成就，各 24 张）发给用户。
