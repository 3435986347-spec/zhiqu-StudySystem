  Markdown 图片写的尺寸、例行完成的进度条宽度；弹层 / 菜单 / 提示的定位、弹窗锁滚动时补的右内边距、面板展开的宽度（JS 里写的这几样）。
- **固定的样子，进样式表**：看板的骨架（上下一列、四个数字、左右两栏、右栏粘在顶上、卡片头、本周的翻页按钮、番茄钟的表盘中间、下面一行数）、
  看板里的两行截断、象限色的小圆点（只有四个象限 + 例行五种，按象限挂类）；共用层的询问框 / 确认框的说明段落、`empty()`、接口不可用页、
  登录 / 注册（两个页签、表单、记住登录）、任务表单（说明框、截止前提醒一行、说明、警告条）、代码着色（四种颜色 → 四个类，新编辑器跟着用类）、
  侧栏头像卡、外观弹层的小标题；成就 / 设置两页的「正在打开…」、任务页的外层包裹。
- **按状态变的，靠类和 `aria-*`**：登录 / 注册页签（原来 JS 写 `fontWeight / color / borderBottomColor / display`）、持久通知关闭时的淡出、
  右键菜单的样子和悬停（原来 `cssText` + `onmouseenter / onmouseleave` 写底色）。
- **一个 HTML 错**：看板里套了第二个 `<main>`（外层已经是 `main.zq-main`）。
- **手机样式里按内联字面认元素的两条规则**（`.zq-main [style*="grid-template-columns"]…` 压成一栏、`[style*="repeat(4"]…` 两个一排）：
  全站只剩看板这两处内联网格在靠它们。挪走以后这两条没人用了 —— 删掉，看板的类自己写手机上怎么排；`MobileLayoutTest` 原来要求「至少扫到 3 处内联网格」，
  改成「一处都不许有、手机样式里也不再有按 style 认的规则」。

## 计划
1. 看板：`dashboard.html`、`pages/dashboard.js` 的固定样子进 `.zq-dash-*`；手机上四个数两个一排、左右两栏变一栏、右栏不粘顶；内层 `<main>` 换成 `<div>`。
2. 共用层：`zhiqu-api.js`、`zhiqu-ui.js` 的固定样子进样式表；状态靠类 / `aria-selected` / `hidden`；代码着色换成类（阅读、新编辑器两处）。
3. 零散的三处（成就、设置的占位段落，任务页的包裹）进样式表。
4. 判据：`InlineStyleRatchetTest` 的数改小，剩下的每一处都要是上面「按数据变的」那几种（写成一张有理由的表）；`MobileLayoutTest` 改写；
   挪之前把每条内联声明对一遍 `src/test`（第七十九轮的教训：认字面的判据在代码搬走后会自动变绿）；字号收进令牌，写死的字号种数应该少几种。
5. 改前改后在内置浏览器里逐块量（看板 1440 / 375、浅 / 深；登录框、任务表单、询问 / 确认框、右键菜单、侧栏头像、代码着色），扰动见红、真浏览器暴力、全量、换缓存令牌、截图。

## 结果
**样子挪进样式表**
- 全站内联 `style=` **81 → 6**，剩下的都是按数据变的（`InlineStyleRatchetTest` 的 `DATA_ONLY` 一处一处写着是什么、源码里真的在、条数对得上）：
  统计 / 后台柱子的高 `--v`、图谱图例 `--c`、资料卡片 `--srcc`、`openModal` 给的宽度、Markdown 图片写的尺寸。JS 里改样子：共用层 17 → 5（锁滚动补的右内边距、菜单的位置）。
- 看板：骨架进 `.zq-dash*`；四个数复用统计页的 `.zq-stat-grid` + `zq-phone-2col`、两栏 `.zq-dash-cols` + `zq-phone-1col`；内层多出来的 `<main>` 换成 `<div>`；
  卡片头用例行计划、统计两页同一条 `.zq-card-head`（起先自己又写了一条同名的、下边距 14，量出来被那条压成 12 才发现撞名 —— 删掉自己那条）；
  两行截断、象限色小圆点（`.zq-qdot[data-q]`）、番茄钟的表盘 / 按钮 / 下面一行进样式表。
- 共用层：询问 / 确认 / 说明框的段落、`empty()`、接口不可用页、登录 / 注册（页签看 `aria-selected`、两张表 `hidden` 切）、任务表单、代码着色（四个类 `.zq-tok-*`，新编辑器跟着用类）、
  右键菜单（样子和悬停进样式表，JS 只写位置）、侧栏头像卡、外观弹层；成就 / 设置的「正在打开…」、任务页的包裹。
- 手机样式里按内联字面认元素的两条规则（`[style*="grid-template-columns"]`…）没人用了，删掉；`MobileLayoutTest` 从「每种内联网格怎么排都决定过（至少扫到 3 处）」
  改成「一处内联网格都不许有、手机段里不许再有按 style 认的规则、看板的网格带着手机上的排法」。

**改前改后逐块量**（内置浏览器，同一个账号；改前的数存在浏览器里，改后逐个属性比；看板 1440 / 375，浅 / 深；任务表单、空清单、代码着色、右键菜单、确认框、询问框、登录框）
- 一模一样的：任务表单（浅 / 深）、代码着色的颜色（浅 / 深）、看板上所有颜色 / 字重 / 截断 / 网格（四个数两个一排、两栏变一栏照旧）。
- 有意改的：卡片头下边距 14 → 12（和另两页一致，下面的内容上移 2–6px）；本周翻页的左右两个按钮 32 → 30（原来和「本周」差 1px）；
  字号收进令牌：番茄钟两处 11.5 → 12、侧栏名字 / 空清单 / 右键菜单 12.5 → 13、确认框正文 13.5 → 13；
  登录页签：原来打开时 JS 就把选中的写成 700（不合字重规矩），现在选中 500、没选中 400；标红的确认按钮：原来红底配主色边（浅色黑边、深色深色字），换成 `.zq-btn-danger`；
  右键菜单的影子用 `--zq-sh2`（和头像菜单一样）。
- 量出来的我自己的错：多行询问框的最小高度写在 `#zq-ask-input` 上，单行的输入框也是这个 id，被撑到 100px —— 改成 `textarea#zq-ask-input`，加了判据。
- 原来就坏的：持久通知关掉时想淡出（JS 写 `opacity:0`），可入场动画停在最后一帧会压过它，从来没淡出过、220ms 后直接消失；撤掉动画再改 opacity 也不行（浏览器不起过渡，当场就没）——
  换成一个淡出动画，量过：0.2 秒里 1 → 0.78 → 0.42 → … → 0，然后才拿掉。

**两件插进来的**
- 后端工作区的扩展名白名单和命令行对齐（加了 svg、mjs、ini、lua 等 13 种不含密钥的文本），`WorkspaceExtensionsTest` 读 guard.js 的 `DEFAULT_EXTENSIONS` 比两边、svg 能写、`.env` / 私钥 / 证书照样拒；
  `CodeContextPrompt`：照旧不许拿整份代码凑数，例外是用户明说要把完整内容放在对话里、或者写入因为类型 / 位置被拒（再试也一样）—— 这时整份放进代码块，告诉他存成什么文件名。
  这条没有拿真模型从头走一遍（要花钱、要配工作区），是判据 + 提示文本。
- 外壳：先放出胶囊、记下在迷你模式，再藏主窗口；迷你模式下不因为「最后一个窗口关了」退出；展开回到主窗口时清掉迷你模式（点红色按钮关主窗口照旧退出、后端跟着停）。
