# 第六十七轮（2026-10-15）：Wiki 只读模式、网址点击与 JSON 内部滚动

## 用户问题与计划

- 正文中的裸 HTTP(S) 网址显示为普通文字，希望像 Obsidian 一样可以直接点击跳转；截图处于排版编辑态，不能只补阅读态。
- 自动识别裸网址及角括号链接，保留查询参数、编码和原 Markdown；代码/公式和已有链接不重复识别。
- 阅读和排版编辑中的外部链接单击打开，桌面外壳沿用系统浏览器路由；保留当前编辑和草稿，拖选文字、源码模式及私有附件使用各自原行为。
- 用户追加只读模式：默认只读，正文点击不进入编辑；明确“编辑 / 保存并只读”切换，阻止标题、勾选与粘贴/拖入等操作越过模式，保存失败保留编辑和草稿。
- 引用的长 JSON 在预览中鼠标滚轮无反应；定位真实滚动容器，修复自然嵌套滚动，不用全局 wheel 拦截强行锁住页面。
- 新判据先红后绿，用合成资料做真实浏览器/WebKit 验证；不访问截图里的内部网址，不改真实 Wiki、数据库或模型。
- 同步缓存、首页截图、round 索引，离线回归、审查后提交推送。

## 实现

### 网址识别与点击

- 裸 `http://`、`https://` 以及 `<https://…>` 渲染成外部链接，保留查询参数、百分号编码、锚点，以及网址内的星号、下划线和美元符。中英文句尾标点及未配对括号留在链接外，网址中的配对括号保留。
- 识别顺序先保护行内代码、图片、笔记/附件嵌入及已有 Markdown 链接，再处理公式与裸网址，避免嵌套锚点和链接内容被强调语法改写。HTML 属性和显示内容转义，只接受合法的 HTTP(S) 外链。
- 阅读和排版编辑共用事件委托，单击、中键及聚焦链接后回车均可打开；多次渲染不会重复绑定。保留文字拖选和编辑光标的回车行为，源码及私有附件继续使用原入口。
- 外链通过 `window.open(..., '_blank', 'noopener,noreferrer')` 打开，桌面外壳继续交给系统浏览器。不会把原生路由正常返回的 `null` 误报为弹窗失败。
- 自动链接保存原始 Markdown 标记；未修改时裸网址、角括号网址原样往返，修改显示文字或目标后保留修改，不用旧标记覆盖用户输入。

### 默认只读与明确编辑

- 顶部增加“只读 / 编辑中”状态和“编辑 / 保存并只读”按钮。打开已有页默认只读，点击正文只选文字；明确点击编辑按钮或右键“编辑本页”才进入编辑。
- 只读时禁用格式工具、源码切换、改标题和任务勾选；粘贴/拖入图片不上传、不自动切编辑，文件拖入仍阻止浏览器离开知识库。外链、双链、附件与 JSON 阅读和滚动保持可用。
- “保存并只读”沿用现有乐观锁保存；成功才返回只读，失败保留当前排版/源码和草稿。保存期间继续输入时，已提交内容与后续草稿分开处理，不强制退出编辑或丢字。取消编辑回到只读并保留阅读位置。
- 状态标记和模式按钮预留宽度，格式栏只禁用、不因模式切换移除，避免按钮文字变化使工具栏重新换行。阅读与编辑仍使用相同正文布局及视口锚点恢复。
- 新页正文请求开始前立即关闭旧页编辑会话，加载期间禁编辑，防止把 A 页旧 DOM 的输入记为 B 页草稿；正文取回失败也不允许编辑摘要替代完整正文。关闭最后一个标签时保存原页草稿并退出编辑。
- 改名、链接/公式/参考链接弹窗、旧草稿冲突确认、图片选择器及上传回执检查页面、编辑会话和登录身份；迟到响应不能修改已回到只读或另一编辑会话的正文。嵌入笔记里的任务框始终是预览，不因父页进入编辑而启用。
- 这是当前知识页的阅读模式；来源导入、附件列表和新建页等知识库管理入口保持原有功能。

### JSON 内部滚动

- 原因是 JSON 外层有纵向 overflow，而内部 `<pre>` 又被共享代码块样式设为横向滚动节点，WebKit 会把指针下的滚轮交给没有高度限制的内层节点，真正纵向容器不滚。
- 改成 `<pre>` 同时承担横向和纵向滚动，高度上限 460px；外部文字包装层不再创建第二个滚动面。正文与附件弹窗、阅读与编辑都共用此规则，不增加全局 wheel 拦截。
- 长行保留横向滚动，长 JSON 在固定高度内纵向滚动；不修改 JSON 原文、嵌入 Markdown 或附件鉴权。
