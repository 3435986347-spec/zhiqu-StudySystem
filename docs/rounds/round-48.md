# 第四十八轮（2026-10-08）：界面打磨第 5 步 —— 看板

## 由来
`docs/ui-plan.md` 第 5 步。用户 2026-10-08：「先review一遍，push，然后接着做step5」（review 是第四十七轮）。
之后用户的设想（同一天）：桌面应用缩成一个悬浮的迷你番茄钟（像网易云音乐的桌面歌词），以后也许变成宠物 —— 这一轮不做，第 5 步做完再出方案、问用户。

## 现在是什么样（2026-10-08 量的，示例账号和用了一阵子的账号各看了一遍）
- **本周日历**：七个格子各 225px 高、每天最多五个灰块「08:00 例…」，标题截到只剩一两个字 —— 没信息，还是页面上最重的一块；格子 108px 起，窄一点就横向滚。
- **四个数字卡**：「逾期未完」不管是几都是大红字，0 也红。
- **行动清单**：每一条一个带底色的小卡片，例行计划另一种底色；只能看今天。
- **象限摘要**：四张卡、顶上一道 3px 的彩色边、每条任务一块彩色底 —— 四种颜色铺满一片。
- **临近 DDL**：每一条右边一个一模一样的「DDL」徽标，什么也没说。
- **番茄钟**：190px 的环、上下松，一张卡占了右栏大半屏。
- 每张卡标题上面还有一行小字（「本周日历」「今天」「象限摘要」「临近 DDL」），第 3 步页面头部去掉过一次，卡片里的还在。

## 计划
1. **本周日历变成一排「日子」**：每天一格 —— 星期、日期（今天是一个实心圆）、一排小点（一个点一件事，颜色是象限，例行计划灰色，做完的变淡，最多 8 个、多了「+N」）、「N 项」。
   七格一排不横向滚；格子是按钮，**点一天，下面的清单就换成那一天的**（再点今天回来），键盘也能点。
2. **清单**：标题跟着选的那天（「今天」/「10/09 周四」）；一条一行、行间一道细线，不再一条一张卡；时间、标题（两行封顶）、象限 / 例行的小标签和说明一行；
   做完的变淡。以后的日子不给「完成」按钮（还没到）。
3. **数字卡**：「逾期未完」平常是正文色，大于 0 时标签旁边一个红点 —— 不再一片大红数字；数字字号不变。
4. **象限摘要**：一张卡里四格，每格一个象限色的小圆点 + 名字 + 件数，下面几条任务一条一行（细线分开），不再整片彩色底。
5. **临近截止**：右边的「DDL」换成还有几天（「今天」「明天」「3 天后」「逾期 2 天」），今天和逾期的用象限 1 的红。
6. **番茄钟收紧**：标题和「今天第 N 轮」一行、环 160px、上下间距收紧。
7. 卡片标题上面的小字去掉，标题直接说是什么（「本周 10/05 – 10/11」「今天」「四象限」「临近截止」）。
8. **判据**：日子的结构（点、件数、今天、选中）在 node 里真跑 `renderWeek`；点一天清单换过去、以后的日子没有「完成」；逾期不再写死红色；截止的相对天数；没有写死的「DDL」徽标；卡片里没有小字标题。扰动见红。
9. 截图（浅 / 深、手机宽）给用户；首页轮播的看板截图跟着重出（界面改了 —— CLAUDE.md 的规矩；`Snapshot` 要开窗口，跑之前问用户）；全量；桌面应用重新打包。

## 结果（2026-10-08）

照计划做完，另外修了两处 bug（一处搬家时留下的、一处暴力测试照出来的）。

- **本周日历**：`.zq-week` 一排七格（`repeat(7,minmax(0,1fr))`，不再 108px 起、横向滚），每格是按钮：星期、日期（今天是实心圆）、一排点（象限色 / 例行灰 / 做完的淡、最多 8 个、多了「+N」）、「N 项」；
  读屏念「周三 2026-10-07，11 项」。点一天，下面的清单换成那天的（`showDay`），标题「10/09 周五」，以后的日子不给「完成」；点回今天是「今天」。选的那天记在 `state.dashDay`，记完番茄钟、跨过零点重新取数据之后还在。
  手机宽：格子里只留星期、日期、点（34px 一格，页面不横向滚）。
- **清单**：一条一行（`.zq-agenda-row`，行间细线），时间、标题（两行封顶）、象限色小点 + 名字和说明一行；做完的变淡。
- **数字卡**：「逾期未完」不写死颜色，大于 0 时标签旁边一个红点（`.zq-stat.is-alert`）；「例行完成」的数字也不再是强调色。
- **四象限**：一张卡里四格（`.zq-quads`，格间一道细线），象限色只留在名字前的小点上；手机上一格一行。
- **临近截止**：右边写还有几天（今天 / 明天 / N 天后 / 逾期 N 天），今天和逾期的红字；按业务日期算（前端的 `today()`）。
- **番茄钟**：标题和「今天第 N 轮」一行、环 160px、上下收紧。卡片标题上面的小字（本周日历 / 今天 / 象限摘要 / 临近 DDL）去掉了。
- **修的 bug 1（搬家时留下的）：例行计划没填时间，看板整页「加载失败」**。看板的模块里直接调 `hm(…)`（时:分），可第三十五轮把看板搬成模块时 `hm` 没从壳里给过来 ——
  例行计划没填时间时 `time` 是空的，`it.time || hm(it.deadline)` 一走到 `hm` 就 ReferenceError，整个看板换成「页面接口暂时不可用 hm is not a function」（真浏览器里把绑定拿掉复现过）。
  → `zqShared` 给出 `hm`、看板解构它；`PageModulesTest` 原来只核对 `zqShared` 里有的名字，现在壳里定义的所有函数都核（模块里直接调了、却没给过来的），一加上就照出了这一处。
- **修的 bug 2（暴力测试照出来的）**：① 换过周再点「本周」，一格都没选中（选的那天还记着别的周）→ 不在这一周的选中清掉；
  ② 连点「上一周 / 下一周」，几次请求一起在路上、回来的先后不一定，回来晚的盖掉最后一次 → 只画最后一次的（序号）。

**判据**：新的 `DashboardLookTest` 两条 + `dashboard-check.js` 23 条（在 node 里真跑 `renderWeek` / `showDay` / `renderToday` / `renderQuadrants` / `daysUntil` / `dueLabel` / `renderDeadlines`）；
`PageModulesTest` 加「壳里的函数没给过来就被调用」；`MobileLayoutTest` 内联网格的下限跟着降（看板的 4 种网格挪进了样式表的类 —— 方向如此）。
扰动 16 个全红（今天不标、做完的点不淡、多了不写 +N、点了不记、以后的也给完成、标题不换、还有几天差一天、今天和逾期不标红、象限又是彩色顶边、卡片标题上又有小字、逾期又写死大红、逾期大于 0 不标、
换过周的选中不清、连点换周不看先后、hm 又没给模块、日历又横向滚）；走 node 的 9 个另外直接跑过，各自红在想照的那一条上。

**暴力测试**（内置浏览器）：连点日子 30 次 → 只选中最后点的那一天；下一周、下一周、上一周连点 → 停在下一周、选中那周第一天；「本周」→ 回到今天、只选中一格；上一周 / 下一周交替连点 6 次再「本周」→ 本周、今天；控制台没有报错。
给验证账号加了一个没填时间的例行计划（`zhiqu_verify`，留给用户删），看板照常打开、那一条时间空着。

**截图**（发给用户）：浅色（示例账号）、深色、点了周五、四象限与临近截止（用了一阵子的账号）、手机宽。首页轮播里看板那张要重出 —— `Snapshot` 要开窗口，问用户。
