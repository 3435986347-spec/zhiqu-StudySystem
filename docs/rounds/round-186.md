# 第一百八十六轮（2026-11-26）：直接 shell 不执行写到工作区外的命令

`docs/harness-next-plan.md` 第 10 步。Windows 桌面 auto 没有系统沙箱，原来命令能写到当前用户有权限的任何路径。

## 计划

执行前看命令文本：重定向、`cd` 到外面、`cp` / `mv` / `rm` 的最后一个路径、`writeFile` 一类调用的字符串参数，落在工作区外或 `.git` / `.zhiqu` 里就不跑。相对路径照常写。读工作区外的路径不拦。程序运行后自己拼出来的路径，这一层看不到，结果里写明。

## 结果

把拒绝改成始终返回空时，`echo` 写到临时目录外的文件退出码是 0，新断言要的是 126（Failures）。改回之后：工作区外、`.git/hooks`、`writeFileSync` 的绝对路径都不落盘，`echo yes > inside.txt` 写得进去。
