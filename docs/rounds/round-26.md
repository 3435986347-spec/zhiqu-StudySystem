# 第二十六轮（2026-10-04）：定位落地 —— 「知趣·象限 AI 办公助手」

## 由来
`docs/product-plan.md` 第 3 步。用户 2026-10-04 定了第四节 1–4：先做个人；保留「知趣·象限」、副标题「AI 办公助手」；
学习统计改专注 / 工作统计、成就从导航收起（数据不删）、参考计划改办公模板分类、番茄钟 / 例行计划 / 四象限只改文案；以桌面 / 本机为主。

开工前数了一遍：页面和壳里「学习」44 处、「考研 / 备考 / 学生 / 学校 / 专业」十来处；**最重的一处在 AI 自己**——
对话的系统提示写着「你是『知趣·象限学习系统』的 AI 助手，帮助大学生做学习规划、DDL 拆解、复习节奏」，
计划落库、计划转任务、图片识别、长期记忆的提示也都是学生口吻（「大学课程通常 45 或 90 分钟，自习通常 120 分钟」、
记忆示例「目标是 2027 年考研」）。界面改了而 AI 照旧自称学习助手，定位就只落了一半。

## 计划（开工时）

1. **名字**：14 个页面的标题「X - 知趣·象限 AI 办公助手」；落地页「知趣·象限 · AI 办公助手」；`manifest.json`（安装到桌面的名字）；
   侧栏品牌；README / CLAUDE.md 的项目一句话。桌面应用的包名「知趣象限」不动（装在用户机器上的东西改名要迁移目录，不值）。
2. **AI 放第一位**：侧栏里 AI 助手排第一；登录后落在 AI 助手；看板上有一个去 AI 助手的入口。
3. **AI 的口吻**：对话、计划落库、计划转任务、图片 / 文件识别、长期记忆、对话摘要的系统提示改成办公助手（个人的工作、
   日程、截止事项、会议、项目；学习只是用户可能做的事之一，不是前提）。意图判断的**关键词表不动**（「考研计划」照样要认得）。
   计划工具的描述里「学习计划」→「计划」。
4. **专注统计**：「学习统计」→「专注统计」，「学习时长」→「专注时长」，「连续学习天数」→「连续专注天数」；看板番茄钟的说明、
   记录接口的报错（「学习日期…还没到」）跟着改。接口字段名（`studyMinutes` 之类）不动 —— 那是内部的。
5. **成就**：从侧栏收起；页面本身还在（直接打地址能进），数据不删。解锁时如果有弹出提示，看情况一起收起来（导航里没有、却弹「解锁成就」是矛盾的）。
   成就定义里的「学习任务」「累计学习」改成「任务」「累计专注」（新迁移按 code 更新名字和说明）。
6. **参考计划的分类**：新迁移把四个种子分类改成办公方向（key 不变，已有模板照旧对得上），再加几个办公分类；
   `SharedPlanServiceImpl.ensureGeneratedCategory` 里写死的「考研 → 考试备考」那一套同步改（它和库里的名字是两份，不一起改就会出现两种叫法）。页面文案改。
7. **个人资料**：「学校」「专业 / 年级」→「单位 / 学校」「部门 / 职位」（已有的值照旧有意义，不迁数据）。
   顺带：这几个输入框的 HTML 里还写着设计稿的 `value="王明远"` `value="沪上理工大学"` —— 第二十四轮的扫描只看文字、没看属性。
   启动时会被真值覆盖所以没露出来，但它就是示例数据；删掉，并让「页面里没有示例数据」那条判据也看 `value=` 属性。
8. **落地页**：标题、文案、轮播里的产品示意图换成办公场景（第二十四轮留到这一步的）。
9. **判据**：一份「只对学生的说法」清单（考研、期末、备考、大学生、学习系统、教学周、六级 / 四级、学习统计、学习时长……），
   页面、壳、manifest、AI 的系统提示里都不许出现 —— 去掉注释后扫，扫到的文件数有下限；计划词表、测试样本里的用户原话不算。

### 怎么验
新账号真浏览器走一遍：登录后落在哪、侧栏、每一页的标题和文案、专注统计、参考计划的分类筛选、个人资料；对假模型说话，看系统提示是办公口吻。
页面上逐页扫「只对学生的说法」（第二十三轮那种：启动之后的可见文字）。全量通过、扰动见红；桌面应用重新打包（页面改动不用打包就生效，但标题、manifest 在包里）。

## 结果（2026-10-04）

桌面应用的包名「知趣象限」和内部的类名、表名（`StudyTask`、`study_record`、`create_study_plan`）照计划没动。

那样模型只能瞎编，就改成了普通入口。要不要让 AI 读任务是个产品决定（任务标题会发给模型供应商），留给你。
