# 第七十七轮（2026-10-19）：界面打磨第 8 步（四）—— 后台四页、落地页

## 由来
`docs/ui-plan.md` 第 8 步的最后一段（第七十五轮做了设置 / 成就弹窗）：后台四页（监管后台、账号管理、反馈管理、共享计划审核）和落地页。

## 现在是什么样（验证账号：一个管理员、几个普通用户、16 条反馈、四种状态的共享计划；Chromium 1440 × 900 / 375 × 812，浅 / 深）
**监管后台**
- 六个数里有三个**永远是 0**：「今日请求」「AI 调用」「限流拦截」读的是 `traffic.todayRequests` / `aiRequests` / `rateLimited` —— 接口从来没有这几个字段
  （真实的 `traffic` 是 `last15Minutes`、`lastMinute`、`errorCount`、`averageLatencyMs`、`uniqueIpLastHour`…）。
- 「运行异常」不管是不是 0 都是红的，「开放反馈」不管是不是 0 都是强调色。
- 「近 15 分钟请求量」：接口只给有请求的那几分钟，图上只有两三根柱子挨在一起，时间轴是断的。柱子的高度、颜色是 JS 拼的内联样式。

**账号管理**
- 「最近活跃」那一列的时间被操作按钮盖住、只剩「2026-10-19 09」：操作列给了 128px，三个按钮要 165px 上下，右对齐之后往左溢出。
  这一列显示的也不是活跃时间，是 `updatedAt`（资料最后一次改）。
- 表下那句「禁用后该账号无法登录，数据保留」，载入后被「共 N 个账号」盖掉了。「删除」和别的按钮一个样子。搜索框、角色下拉没有标签。
- 手机上整张表横着滚，角色、状态、操作都在屏幕外。

**反馈管理**
- 筛选按下的样子是 JS 改背景色；没有个数。
- 点「关闭」没走 `safe`（失败了不说、连点发几次）；关完一条整个筛选条重建、回到「全部」。

**共享计划审核**
- 两列的网格把同一行的卡片拉成一样高：「已发布」左边那张下面空一大块。
- 旧数据的分类写的是代码「OTHER」；详情弹窗标题里的状态也是代码（「PENDING」）。

**落地页**：5 处内联样式；标题在 1440 宽时断成「……排得清晰 / 可控」，「可控」单独一行。

`assets/pages/admin.js` 40 处内联样式，四页 HTML 21 处。

## 计划
1. 后台四页的样子进样式表（`.zq-admin-*` 等），`admin.js` 不拼内联样式、不改 `style`；四页 HTML 不写内联样式。
2. 监管后台：六个数换成接口真有的（注册用户、开放反馈、运行异常、近 15 分钟请求、出错的请求、平均耗时），不再摆三个永远是 0 的；
   颜色看数据（`data-state`：异常 > 0 才红、开放反馈 > 0 才强调）。后端把 15 分钟的桶按顺序补满 0，图上是连续的 15 根；柱子高度交给 `--v`（和专注统计一个写法）、零只留底线。
3. 账号管理：列宽只写一处（表头和行同一个类），操作列按内容宽；那一列写「注册于」（`createdAt` 的日期）；说明留着、个数单独一处；「删除」是危险色；
   手机上一行叠成两三行（名字和邮箱、角色 / 状态 / 点数、操作），不横着滚；搜索框、下拉有 `aria-label`。
4. 反馈管理：筛选 `.zq-seg` + `aria-pressed`、写个数；「关闭」走 `safe`、提交着不重发、关完照原来的筛选重画（不重建筛选条）。
5. 共享计划审核：卡片不被拉高；认不出的分类写「其他」；详情标题的状态写人话。
6. 落地页：内联样式进样式表；标题 `text-wrap: balance`。
7. 判据：`admin-check.js` 在 node 里真跑 `pages/admin.js`，替身照接口真实回包写（第六十九轮的教训）；静态：四页和模块没有内联样式、列宽一处、手机规则；后端补满 15 个桶。扰动见红。
8. 真浏览器：1440 / 375、浅 / 深的前后对比；暴力：连点「关闭」、筛选乱点、账号搜索连按回车、启用 / 禁用来回、审核连点。全量；换缓存令牌。

## 结果
**监管后台**（`admin.html`、`pages/admin.js` 的 `adminMetrics` / `metricCard` / `trafficBars`）
- 六个数换成接口真有的：注册用户、开放反馈、运行异常、近 15 分钟请求（下面写最近 1 分钟）、出错的请求、平均耗时（ms）。`todayRequests` / `aiRequests` / `rateLimited` 不再读。
- 颜色看数据：`data-state`，运行异常 > 0 才是 `bad`、开放反馈 > 0 才是 `attention`，是 0 就不上色。
- 后端 `InMemoryTrafficMonitorService.snapshot()` 先把 15 个分钟按顺序填 0，再把这 15 分钟里的请求数进去：图上是连续的 15 根，没请求的那分钟只留一条底线（`.zq-bar.is-zero`）；高度交给 `--v`，是这个模块唯一的内联样式。
- 页头去掉了假的「数据每 5 分钟刷新」（页面不会自己刷新）；「刷新数据」连点几下，画出来的还是六个数、15 根柱子（每次整块重画，不叠加）。

**账号管理**
- 列宽只写在样式表的 `.zq-acct-row` 一处，表头和行同一个类，**每一列都是定宽**。收口前看截图发现：先写的 `max-content`（让操作列按按钮宽）在表头和每一行各算各的 —— 表头的「操作」只有 24px 宽，前面几列整体比数据右移了 66 到 144px。
  改成 176px（三个按钮要 168px），判据改成「列宽里不许有按内容定的轨道」+「最后一列放得下三个按钮」，真浏览器里量表头和每一行的每一格左右对齐。
- 那一列写「注册于」（`createdAt` 的日期，悬停写到分钟）；表下的说明留着、个数单独一格；「删除」是危险色；搜索框、角色下拉有 `aria-label`，搜索框 200 宽（压过全局 `input{width:100%}`），和「查询」在一行。
- 连按回车查几次，只认最后一次（`latestOnly`）；启用 / 禁用连点只发一次（`once`）。
- 手机上表头藏起来，一行叠成：名字 + 角色 + 状态、邮箱、点数 + 「注册于」日期、操作，不横着滚。

**反馈管理**：筛选是 `.zq-seg` + `aria-pressed`，每个按钮写个数；「关闭」走 `once`（失败照实说、提交着不重发），关完照原来的筛选重画，不回到「全部」。

**共享计划审核**：卡片 `align-items:start`，按自己的高度；长标题（一串没有空格的英文）在按钮里换行，不把整页撑宽；接口把认不出的分类代码原样放进 `categoryName`（「OTHER」），前端认出这种情况写「其他」；详情标题的状态写人话（「待审核」）；「通过」连点只发一次审核。

**落地页**：5 处内联样式进页内的 `<style>`；标题 `text-wrap:balance`，宽屏（> 560px）再加 `word-break:keep-all`，只在标点、空格处断，「可控」不再一个人一行。手机上不加 keep-all：320 宽时一行放不下，被强行断开，「，」跑到行首。

内联样式：`admin.js` 40 → 1（柱子的 `--v`），四页 HTML 21 → 0，落地页 5 → 0。

## 判据
- `src/test/resources/js/admin-check.js`（新，30 条）：在 node 里真跑 `pages/admin.js`，替身照接口真实的回包写（`/admin/overview`、`/admin/feedback`、`/admin/users`、`/admin/shared-plans`）；`AdminLookTest`（新，6 条）管页面和样式表的静态那一半；`TrafficMinuteBucketsTest`（新）：15 个桶、按顺序、最后一个是这一分钟、14 个 0。
- `MobileLayoutTest` 的下限降到「≥ 4 处、≥ 3 种」：监管后台的两个网格从内联挪进了类（手机规则在 `AdminLookTest` 里认）；`DesignTokensTest` 内联字重的下限降到 28（又少了一批内联样式）。两处都在注释里写了是这一轮。
- 扰动（`p77a.py`）：21 处，各自在预期的那条判据上红（A2「开放反馈不管多少都强调」第一次跑是绿的 —— 替身里的开放反馈只有 15 条，补了「0 条不上色」那一条之后红）。
- 真浏览器暴力（Chromium，1440 / 375 / 320）：21 / 21。六个数、15 根柱子、刷新连点 6 下、筛选乱点 20 次、双击「关闭」、连按回车 5 下、双击「禁用」再「启用」、按角色查、375 宽不横着滚、长标题不撑破、双击「通过」只审核一次、详情标题、落地页 1440 两行 / 320 不超过三行、没有页面抛错；表头对齐那条在 `max-content` 下红、「日期不被盖住」那条在 128px 下红，各自只在自己那个扰动下红。
  对照（改前的版本）：前两条就红（六个数里是「今日请求 / AI 调用 / 限流拦截」、新柱子 0 根），第三条起页面上没有新的结构，脚本在等元素时超时停下。
- 截图：四页 + 落地页，1440 / 375、浅 / 深，改前改后各 20 张。截图里多出来的「暴力…」账号和计划是暴力测试建的，在 `zhiqu_verify` 里，留给用户删。
- 全量（`mvn -o clean test`，Docker 开着）：1274 个，0 失败，9 个跳过（四个只在 macOS 上跑的桌面应用判据）。
  第一遍有 3 个出错（`PrivateUploadPathGuardTest`、`WorkspaceAccessTest`、`KnowledgeVaultServiceTest`，都是中文文件名 `InvalidPathException`）：容器重启后 shell 的 locale 是 POSIX，JVM 的文件名编码成了 ASCII，和这一轮的改动无关；`LC_ALL=C.UTF-8` 下这三个 20 / 20 过。
