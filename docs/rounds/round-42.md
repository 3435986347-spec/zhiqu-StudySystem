# 第四十二轮（2026-10-06）：界面打磨第 2 步 —— 图标

## 由来
`docs/ui-plan.md` 第 2 步。用户看过第 1 步的调整说「好的」，接着做第 2、3 步，第 3 步做完给截图。
锐评里「玩具感」最直接的来源：导航、菜单、按钮里的图标是 Unicode 符号（✦ ▦ ☰ ↻ ❏ ≣ ◈ ⌘ ✉ ∿ « » ‹ › ⚙ ◐ ⏻ ✪ ＋ × …），每个来自不同字体，粗细、基线都不一样。

## 计划

1. **一套线性图标**：24 格、1.75 线宽、圆头圆角（Lucide 的画法，ISC 许可，在源码里注明）。这台机器上没有现成的 Lucide 包，**不从外网下载** —— 图形照 Lucide 的样子手写进 `zhiqu-ui.js` 的 `ICONS`，
   `ZQUI.icon(名字)` 给出 `<svg class="zq-icon" …>`；静态 HTML 里写 `<span data-zq-icon="名字"></span>`，`zhiqu-ui.js` 启动时填上；页面模块经 `zqShared.icon` 用。认不出的名字给空串、不报错（判据里另外核对用到的名字都有）。
2. **换掉的地方**：侧栏导航 7 项 + 后台 4 项、收起 / 展开、头像菜单（设置、成就、专注统计、界面风格、退出）、两侧面板的收起按钮和竖条按钮、弹窗的关闭、
   看板「让 AI 排一下今天」和周历的前后、AI 助手的新建 Notebook / 工作区设置 / 新内容 / 加载更早的 / 上一层 / 下载 / 移除附件 / 拖拽框、Wiki 的前进后退 / 关标签 / 体检通过、
   参考计划弹窗的关闭、任务页的返回、后台的「查看」。
   **不换的**：快捷键写法里的 ⌘（「⌘/Ctrl + 回车」）、标签页标题里的「✓ 专注结束」（标题里放不了图）、正文里的 →；落地页（`index.html`）的四张功能卡片留给第 8 步（落地页整页重做）。
3. **判据**：用到的每个图标名都画得出来（在 node 里真跑 `zhiqu-ui.js`）、`data-zq-icon` 占位会被填上；页面、壳、模块里不再有那批装饰符号（去掉注释、落地页除外，扫描有下限）。各自扰动见红。
4. 实测：内置浅 / 深各看一遍图标的粗细、对齐（截图在第 3 步之后一起给用户）。

### 怎么验
全量通过、扰动见红；内置浏览器看图标。

## 结果（2026-10-06）

照计划做完。

- **图标**：`zhiqu-ui.js` 的 `ICONS` 27 个（sparkles、layout-dashboard、list-checks、repeat、copy、book-open、chart-column、shield、users、message-square、clipboard-check、settings、award、contrast、log-out、
  panel-left-close / open、chevron-left / right、plus、x、check、arrow-up / down / left、download），照 Lucide 的图形手写（这台机器上没有 Lucide 的包，没去外网下载），ISC 许可声明写在源码里。
  `ZQUI.icon(名字)`、`ZQUI.paintIcons()`（启动时填 `data-zq-icon` 占位，每个只填一次）；壳的 `icon()` 经 `zqShared.icon` 交给模块；设置弹窗用 `sh.icon`。
- **换掉的**：侧栏 7 + 后台 4、收起 / 展开（随状态换 panel-left-close / open）、头像菜单 5 项、两侧面板的收起按钮和竖条按钮、弹窗关闭；
  看板（让 AI 排一下今天、上一周 / 下一周 —— 顺手补了 aria-label）、AI 助手（新建 Notebook、工作区设置、新内容、加载更早的、上一层、下载原件、移除附件、拖拽框）、
  Wiki（前进后退、关标签、体检通过）、参考计划弹窗关闭、任务页返回、后台「查看」、成就卡片的徽章（设置弹窗里那个 ✪，扫描判据照出来的，计划里漏列了）。
  图标挨着文字的地方容器改成 `inline-flex`。「点右上角 ⚙ 选择工作文件夹」这句提示改成「点右上角的设置按钮」。
- **样式**：`.zq-icon` 默认 16px、按钮里 15px、小按钮和面板按钮 14px，颜色跟文字（`currentColor`）。

**实测**（内置浏览器，浅 / 深）：侧栏、头像菜单、看板、AI 助手、知识 Wiki 的图标都是同一套线条、粗细一致；收起 / 展开、面板按钮、关闭都对。

**判据**：`IconSetTest` 三条 —— 用到的每个图标名都画得出来（从源码扫出 NAV 的第三项、`icon('…')`、`data-zq-icon`，交给 `icon-check.js` 在 node 里真跑 `zhiqu-ui.js`；
认不出的名字给空串、占位会被填上且只填一次）、页面 / 壳 / 模块里不再有那批符号（落地页除外）、模块经 `zqShared` 拿图标。
第一次跑红了两处，都是判据自己的：从 `icon(opts.dir==='right'?…)` 里把比较对象 `'right'` 也当成了图标名（改成去掉 `===` 后面的字面量）；文件数下限 25 定高了（今天正好 24 个）。
扰动 7 个全红：少画一个图标、导航又用符号、启动时不填占位、图标没让读屏忽略、弹窗关闭又是叉号字符、模块直接读 `window.ZQUI`、壳没把 `icon` 给模块（后者 `PageModulesTest` 也红）。

**验**：全量 981 / 0 / 0 / 0（开着 Docker）。桌面应用这一轮不单独打包，第四十三轮做完一起打。

**中途用户说**：「在 ai 助手那里，底色和展开旁边的颜色不要区分会不会更好」—— 放进第四十三轮。
