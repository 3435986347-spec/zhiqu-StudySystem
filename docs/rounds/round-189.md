# 第一百八十九轮（2026-11-26）：没有可执行检查时问人一次

`docs/harness-next-plan.md` 画面第 V4 步剩下的半段。第一百八十四轮只拦住宣称达成。

## 计划

核对员说达成、但标准里没有可执行检查时：有人能答就问一次，题目里指到最后一张预览。用户在「其他」里写下测试命令、退出码、报错条数、亮度格或帧差，才把这条写进验收标准并继续。选「先停」、取消、或写下的仍不可执行，就卡住。问不了人（无人值守、exec、子 agent）直接卡住。不写「好看」词表，也不自动采用推荐项。

## 结果

把询问改成不执行时，有人能答的那条停在 blocked，对不上 achieved（Failures）。改回之后：问一次，题目里有「最后一张预览」；写出 `node --test` 才继续并达成。原来没有 `decide` 的形容词标准仍是卡住。
