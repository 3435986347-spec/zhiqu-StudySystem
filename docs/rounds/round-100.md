# 第一百轮（2026-11-02）：模型原地重复同一段话 —— 循环别把它当「话没说完」

## 由来
第九十八轮付费重跑，pytest-5840 第三遍交了空补丁：模型在不调工具的回复里一遍遍重复同一段（「上游的修法是……改成：」后面两份一模一样的代码），
写满单次输出上限 16384 token 被截断，一共三次（每次约 100 秒、6.8 万字）。循环这一侧错了三处：
1. 截断的纯文字一律当成「话没说完」：6.8 万字原样留进历史，再叫它「从断开的地方接着说」—— 它就接着自己那段往下写；
2. 它照那段调了 6 次 `edit_file`，new_string 和 old_string 一模一样（都拒了），可第 3 次起的提醒是「照原文一字不差地拼 old_string」—— 原文没拼错，是没想好改成什么；
3. 接着说的次数用完，这 6.8 万字的重复成了最后的回答（安静模式下还整段打到终端里）。
量过：四轮评测 42 遍里所有长度 ≥ 1500 字的回复，压缩比（zlib）最高 4.99；这三段是 40.7 / 78.4 / 114.5。

## 计划
1. `agent.js`：被输出上限截断、不调工具的回复，压缩比 ≥ 12 且 ≥ 4000 字算「原地重复」。这时
   - 历史里只留开头一段，后面换成「后面 N 字是同一段话的重复，已删掉」；
   - 推的不是「接着说」，而是「你上一次一直在重复同一段话，重复的部分删掉了；别再复述，按已经读到的内容直接调工具去做（拿不准就写个最小复现跑一下）」；
   - 次数照旧算进接着说的上限（不无限推）；用完时交的回答是删过的那段 + 一句说明，不是整段重复；安静模式下不把重复打到终端。
   命令行和网页 / 桌面应用的代码模式是同一份循环（第九十七轮），一起修。
2. 改一段时「新旧一模一样」连着失败：第 3 次起的提醒换成「原文没拼错，是还没定下要改成什么」，不再叫它重拼 old_string。
3. 判据先红；拿第九十八轮那一遍的真实回复做样本（截一段进测试数据，不放整份）；三组全绿。
4. 真模型回放（验证库网关、用户给的测试 key，几毛钱）：把那一遍第 11 次请求原样重发，看会不会再重复；会的话按新的循环走一步，看下一步是不是真的动手。

## 结果
- `agent.js` 的 `repeating`：被截断、不调工具的回复，压缩比 ≥ 12 **而且** ≥ 60% 的字是前面一字不差出现过的句子 / 行（≥ 16 字）才算原地重复。
  只看压缩比会误伤（1200 行的表格压缩比 15.2、一句重复都没有），只看重复句也会（同一句长日志夹着各不相同的哈希：重复 65%、压缩比 5.1）；
  四轮评测 42 遍里 ≥ 1500 字的回复压缩比最高 5.03、重复句最多 33.8%，那三段是 41–114 倍、84–97%。
  认出来之后历史和回答里只留开头 1200 字 +「后面 N 字是同一段话的重复，已删掉」，推「别复述、直接调工具」（照旧算进接着说的两次）；安静模式下推的时候不打，用完时只打一次删过的那段。
- 新旧一模一样连着被拒：本地工具把这种失败标出来（`unchanged`），第 3 次起的提醒换成「原文没拼错，是还没定下要改成什么」。
- 样本：那一遍三条原地重复的回复和第一遍最长的那条正常回复，**整段**压缩进 `test/fixtures/loop-replies.json`（9 KB，带原文 sha256）——
  计划里写的「截一段」不行：截 6000 字只有四个来回，压缩比到不了门槛，测的就不是那次真实发生的东西了。
- 判据 5 条（`repetition-loop.test.js`），扰动 8 处全红：不认重复、去掉重复句那一道（表格红）、去掉压缩比那一道（日志红）、提醒不分新旧一样、
  推的时候也打出来、推的还是「接着说」、用完时不打、本地工具不标 `unchanged`。头一遍有两处扰动没红 —— 日志样本的重复句只有 38%（照不到压缩比那一道）、
  没断言「推的时候不打」—— 加长样本里的重复句、加了断言之后才红。
- **真模型回放**（验证库网关、用户给的测试 key，¥0.30）：那一遍的前 10 次调用照记录回放（工具真跑在副本里），第 11 次回放那条 6.8 万字的重复（没有把第 11 次请求原样重发去看它会不会再重复：那要再写满 16384 token，修的也不是这一步），之后交给真模型 ——
  - 新的推法之后它**没有再重复**（原来又重复了两次，每次 100 秒）；
  - 照样连交了 3 次新旧一样的 `edit_file`，第 3 次拿到新提醒，下一步就真的改了（去掉 `normcase`、删掉不再用的 import），原来同一处拿到旧提醒（「照原文重拼」）之后重读、再交三次一样的；
  - 回放到 21 轮（回放自己的上限）停下时补丁不是空的。改得对不对没评（这一题三遍的修法都不对，见第九十八轮），这里只看循环有没有把它带出来。
- 网页 / 桌面应用的代码模式跑的是同一份循环（第九十七轮），`CodeAgentLoopIntegrationTest` 真起 node 跑它；这一轮没有界面上的改动，真浏览器那段暴力测试没做，真测试是上面的回放。
- 三组判据：后端全量 1291（0 失败、0 跳过）、命令行 288/288（多 5 条）、评测工具 101 过 1 跳。
