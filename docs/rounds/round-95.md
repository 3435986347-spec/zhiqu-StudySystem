# 第九十五轮（2026-11-02）：两份 coding agent 合成一份 —— 第 2 步：Wiki 工具和里程碑计划接上桥，默认换成 js

## 由来
第九十四轮定的三步（见 `round-94.md`）的第 2 步。第 1 步只接了工作区的读、草稿、跑命令；开关是 js 时，刷题环路要用的 Wiki 工具
（`search_wiki` / `read_wiki_page` / 判过题之后的 `create_wiki_patch`）和项目引导的「把里程碑排成任务」（`create_study_plan`）都没有。

## 计划
1. **桥上加「远程工具」**：命令行那份循环本来就用 `api.post('/api/harness/tools/call')` 调远程工具 —— 宿主把它接到桥上（`tool` / `tool_result`）；
   后端照旧由 `CodeWorkspaceAgent` 那一套执行（`WikiToolAgent.executeWikiTool`：保留页、没读全不许整页覆盖、本轮幂等、可信快照基线；`recordMilestonePlan`），
   不另写一份。下发和执行同一份清单：一直给的那几个随 `run` 发过去；`create_wiki_patch` 等真的跑过一次命令才出现（宿主每一轮重建工具表），后端执行时照样核。
   结果里的里程碑计划、Wiki 待合入草稿照旧交回主流程。
2. **默认换成 js**：`app.ai.code-agent.engine` 默认 `js`；`cli-dir` 没配时按工作目录找 `zhiqu-cli`（开发时从仓库根或 `zhiqu-backend` 起都找得到）；找不到 node 或脚本照旧退回 Java。
   桌面应用要等第 3 步把 node 和命令行源码打进安装包 —— 在那之前桌面上照旧是 Java。
3. 第九十四轮留下的两件：网页代码模式的模型调用记不记进命令行的用量表；「再跑一下」时循环拿对话里上一次的结果回答（0 轮）。
4. 判据先红；真浏览器里不开开关（默认）走一遍刷题环路：出题 → 跑 → 记薄弱点页草稿。

## 结果
- **桥上的远程工具**：宿主把 `api.post('/api/harness/tools/call')` 接到桥上（`tool` / `tool_result`）；后端 `CodeWorkspaceAgent.remoteTools` 照旧用 `WikiToolAgent` / `recordMilestonePlan` 执行，
  同一个循环状态 —— 里程碑计划、Wiki 待合入草稿照旧交回主流程。`create_wiki_patch` 真的跑过一次命令才下发（宿主每一轮重建工具表），后端执行时也核（没下发的照样拒）。
- **默认 js**：`app.ai.code-agent.engine` 默认 `js`，`cli-dir` 留空按工作目录找 `zhiqu-cli`；找不到 node / 脚本退回 Java（桌面应用的工作目录是 /，第 3 步打包之前照旧是 Java）。
  集成测试钉成 java（假模型说的是 Java 循环的格式），js 由 `JsCodeAgentTest` 真起 node 测。网页代码模式的模型调用不记进命令行的用量表（网关多一个 `metered`，原来就不记）。
- **真浏览器（默认设置）点出两个编造**，都是 0 轮就交活：一回说「已生成三个文件的草稿」（一份都没有）；一回说「跑了 test_two_sum.py，输出 ok，三组断言全过」（解法还是 `return []`，根本没跑）。
  原因：网页给的历史只有每一轮的问和最终回答，原样当成一问一答放进去，模型学的是「不调工具直接答」，照着上一次的结果编。改了两处结构：
  前面的对话合成一段带标注的参考（「里面的结果是当时的，这一次用工具重新查、重新跑」），不当成示范；宿主核对说法和事实 —— 说生成了草稿却一份没有、说跑了却没跑过命令，推一次让它照实做（`ctx.claimCheck`，命令行里没有这个钩子）。
  草稿模式的环境说明也不再给一句现成的「改动已生成草稿」让它照念。之后同一句话：真跑了测试（退出码 1）、读了两个文件、查了薄弱点页、生成了 Wiki 草稿（PENDING），结论对。
- **后端执行器的老口子**：`WorkspaceExecutor` 给子进程的 HOME 是工作区本身 —— macOS 的 python3 把缓存写进了用户项目的 `Library/Caches`（真浏览器测试的临时工作区里冒出来的）；
  仓库里带的 user site `sitecustomize.py` 会被任何一句 python3 执行（命令行第九十轮修过同一个口子，这边没跟上）。现在是自己的空目录（0700）；建不出来就不跑。判据照真的做法复现了这个口子（回到老写法时「sitecustomize.py 被执行了」）。
- 「再跑一下」那句进了命令行和网页共用的提示词。
- 判据：命令行 5 条（远程工具经桥、跑过命令才给记薄弱点、草稿说法核对、跑过说法核对、历史当参考）、后端 4 条（远程工具经桥执行、远程工具清单、里程碑交回主流程、不计量）+ 执行器 HOME 1 条；
  扰动：命令行 12 处、后端 8 处，全红（「里程碑交回主流程」头一回绿着，补了一条经桥记里程碑的样本才红）。
- 三组判据：后端全量 1344（0 失败、0 跳过）、命令行 281/281、评测工具 99 过 1 跳。
