# 第五十二轮（2026-10-09）：界面打磨第 6 步 —— 任务页

## 由来
`docs/ui-plan.md` 第 6 步：「筛选条改成一行工具条（搜索 + 分段筛选 + 更多）；表格密度、行内操作悬停才出现；按钮颜色有语义」。
迷你番茄钟三步（第四十九到五十一轮）做完，用户选了「我自己打开试」悬浮窗；回到界面打磨。

## 现在是什么样
- 一张卡片里五个下拉（象限 / 状态 / 优先级 / 排序 / 方向）+「查询」+ 一个手调的绿色描边「新建任务」—— 像老式后台模板，绿色没有语义；改了下拉还要再点「查询」。
- 没有搜索：几百条任务里找一条只能翻。
- 表格每一行是一长串内联样式拼出来的（`grid-template-columns` 写了两遍：表头一遍、每行一遍）；象限是一块彩色底的徽标（看板第 5 步已经改成小圆点）；
  每一行都摆着「编辑」「删除」两个按钮；逾期的截止时间和别的一样；页脚一行「点击状态徽标可快速流转」、总数藏在页脚左边。

## 计划
1. **页头**：「任务」+ 一行小字「共 N 条」，右边主按钮「新建任务」（黑白的主按钮，不再绿色）。
2. **一行工具条**：搜索框（标题和说明里找，打字停一下就查）、状态分段（全部 / 待办 / 进行中 / 已完成）、「筛选」按钮展开第二行（象限、优先级、排序）——
   有筛选条件时按钮上写几个；改了就查，不要「查询」按钮。没有结果时说「没有符合条件的任务」并给一个「清除筛选」。
3. **搜索放在服务端**：标题和说明是加密存的，数据库里搜不了 —— `/task/page` 加 `keyword`：取出这个人符合别的筛选条件的（同样的顺序），解开之后找、再分页；
   最多看 5000 条（用了两年的账号几千条），超过了只在前 5000 条里找，并且说出来。
4. **表格**：行、表头、单元格都变成样式表里的类（列宽只写一处）；象限是小圆点 + 名字（和看板一样）；逾期没做完的截止时间红字；
   编辑 / 删除换成两个图标按钮，悬停或键盘移到这一行时才出现（手机上一直在）；点标题也能编辑；状态那颗胶囊照旧点一下换到下一个状态，说明挪到它的提示里。
5. **判据**：服务端的关键词搜索（集成测试：中英文、说明里的、和筛选一起、分页、超过上限说出来）；工具条和行的画法在 node 里真跑 `tasks.js`；
   页面里不再有绿色手调按钮、行里不再拼列宽；扰动见红。
6. 真浏览器暴力测试（连着打字、乱序回来的搜索结果、连点分段、狂点状态胶囊）；截图（浅 / 深、手机宽）给用户；全量；桌面应用重新打包。

## 结果（2026-10-09）

照计划做完；真浏览器里照出两处（编辑 / 删除在窄窗口里滚出去、手机上一行横着滚），一起改了；另修了一个老毛病（截止早的在前时没截止时间的排在最前）。

- **页头**：「任务」+「共 300 条（先显示 100 条）/ 找到 60 条」，右边主按钮「新建任务」（黑白主按钮，不再是手调的绿色描边）。浏览器标签页的标题跟着改成「任务」。
- **一行工具条**：搜索框（标题和说明里找；打字停 300ms 才查，回车马上查）、状态分段（全部 / 待办 / 进行中 / 已完成，`.zq-seg`）、「筛选」展开第二行（象限、优先级、排序：最近改过的 / 截止早的 / 截止晚的 / 优先级高的在前、清除筛选）；
  收起时按钮上写「筛选 · 2」。改了就查，「查询」按钮没了。连着打字、连点分段时只认最后一次（`latestOnly`）。没有结果：「没有符合条件的任务」+「清除筛选」；什么都没筛还是空的：「还没有任务」。
- **服务端搜索**：`/task/page?keyword=`（`StudyTaskService.page` 多一个带 keyword 的重载，原来那个照旧）。标题和说明是加密存的、数据库里 LIKE 不了 ——
  按同样的筛选和顺序取出来（最多 5000 条，多取一条看超没超）、解开、不分大小写地找、再分页；超过上限时 `searchCapped`，页头写「只在前 5000 条里找了」。
- **截止早的在前**：MySQL 升序里 NULL 在最前，原来选「截止时间 · 升序」先看到一屏没有截止时间的（老毛病，新的排序下拉一选就露出来）——
  `QueryWrapper` 先加一条 `deadline IS NULL` 的排序，再 `.lambda()` 接着写原来的条件（两者共用一个查询）。
- **表格**：表头、行、单元格都是样式表里的类，列宽只写在 `.zq-task-grid` 一处（原来表头一遍、每一行又拼一遍内联样式）；象限是小圆点 + 名字（和看板一样）；
  截止和提醒挤进一格（提醒是下面一行小字），今年的不写年份；逾期没做完的截止红字；做完的整行变淡；进行中的状态胶囊重一点，「点一下换到下一个状态」挪进它的提示；
  编辑 / 删除是两个图标按钮（新图标 `pencil` / `trash-2`，还有 `search` / `sliders-horizontal`），悬停或键盘移到这一行时出现，点标题也能编辑。
- **照出来的 1：编辑 / 删除在窄窗口里滚出去看不见** —— 原来表格最少 880px（改版第一稿 860），1024 宽的窗口里正文只有 750 上下、桌面应用最窄（960）时 680：
  最右边那一列要横着滚才看得到（老页面一样）。截止、提醒合成一格之后最少 640，960 的窗口里不横着滚（判据钉着 ≤ 680）。
- **照出来的 2：手机上一行横着滚** —— 状态、时间、编辑删除都在屏幕外。手机宽（最后那段 `@media`）里一行改成标题一整行、下面象限 · 优先级 · 状态 · 时间 · 编辑删除放不下就换行，表头藏起来，编辑删除一直在。

**判据**：新的 `TasksLookTest` 三条 —— `tasks-check.js` 26 条（真跑 `tasks.js`：条件 → 参数、「筛选」上的数、时间写短、一行的样子、打字停一下才查 / 回车马上查、只认最后一次、没结果的两种说法、清除筛选）、
页面（没有「查询」、没有手调颜色、新建是页头主按钮、分段四个、列宽不写在页面和模块里、控制器接 keyword）、样式（列宽定义一次、最小宽 ≤ 680、键盘移到时出现、手机上一直在且不横着滚）；

乱序回来盖掉、工具条接两遍、象限又是内联颜色、逾期不标红、做完的也标红、提醒不显示、清除不清搜索框、没结果不给清除、上限不说、回车不马上查；样式：表格又太宽、键盘看不见编辑删除、
