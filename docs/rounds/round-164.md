# 第一百六十四轮（2026-11-22）：CLI 离散选项统一键盘交互

用户要求：斜杠命令列出模型、会话、档位后，不应再要求手输 `/model 1` 这类编号；`/effort` 合并进 `/model`。除 `/model`、`/mode`、`/resume` 外，其他“先列清单、再输编号操作”的命令也一起改进。本轮先写方案，确认后才改源码。

## 现状

- `commands.js` 的斜杠菜单只负责选命令，Enter 执行无参数命令；具体业务列表仍由 `cli.js` 打印文字。
- `/model` 只列模型并提示 `/model <id>`；`/effort` 单独显示五档；`/mode` 只打印三档。
- `/resume` 虽能用 `ui.ask` 输入编号，但没有上下键和当前项；本地会话与应用对话分两段编号。
- `/agents` 要再输 `/agents <编号>` 看结论；`/stop` 要再输任务 id；`/memory` 要用 `/memory rm <编号>` 删除。
- `/ps`、`/skills`、`/mcp`、`/state`、`/usage` 等只是信息展示，没有自然的后续选择动作；`/window` 是自由数字输入，不属于离散选择。

## 交互方案

### 一个共用的业务选择器

- 在 `Ui` 增加独立于“斜杠命令补全”和 `ask_user` 的列表选择器：标题 + 最多 8 行可见条目 + 当前项 + 键位提示。
- **↑↓ 移动、Enter 确认、Esc 取消**；超过一屏滚动，选中项始终可见；窄终端按显示宽度截断，不留重绘碎片。
- 默认高亮当前值，不自动应用；只有 Enter 才产生副作用，Esc 保留原模型、档位、会话、任务和笔记。
- 选择器打开时更新输入提示，不能和命令菜单、历史翻页、补充信息、Ctrl+C 或正在运行的队列互相抢键。

### `/model`：模型与思考强度一个面板

- **↑↓ 切换模型，←→ 切换 instant / medium / high / extra / max，Enter 一次应用模型和思考强度，Esc 全部放弃**。
- 显示当前模型、模型名、是否支持工具、当前思考强度；移动过程只改预览，不写配置。
- 应用模型沿用现有“只对本次会话有效”语义；思考强度沿用现有保存到用户配置的语义。打开面板时刷新模型清单，失败不改变任何现有值。
- `/effort` 从斜杠菜单和 `/help` 移除；无参数 `/effort` 作为隐藏兼容别名打开同一面板。
- `/model <id|default>`、`/effort <档位>` 保留旧参数形式，兼容已有习惯、脚本与测试，但不再是界面推荐路径。
- 直连模式不能经服务器换模型时，模型区说明本地配置位置，仍可在同一面板调整思考强度。

### 其他离散选择命令

- `/mode`：↑↓ 在 plan / ask / auto 间移动，Enter 切换并复用现有权限清理，Esc 不变。
- `/resume`：本地会话与应用对话一个可滚动清单，保留来源、时间、消息数和“只有文字”标记；Enter 接入选中项，不再手输编号。显式编号 / session id 参数仍兼容。
- `/agents`：↑↓ 选子 agent，Enter 打开现有结论报告；空清单和 agents 关闭时仍显示原说明。
- `/stop`：无参数时列出正在运行的后台任务，Enter 后二次确认才停止；提供“全部停止”项，也必须确认。`/stop <id|all>` 保留。
- `/memory`：↑↓ 选笔记，Enter 看完整内容；`/memory rm` 不带编号时进入删除选择，Enter 后二次确认，显式编号删除保留。

### 明确不改

- `/ps`、`/skills`、`/mcp`、`/state`、`/usage`、`/help` 等只读输出不为了“统一”而增加无意义弹层。
- `/window` 的窗口大小、`/goal`、`/review` 等自由文本或数字输入不改成固定选项。
- `/system reset` 等危险操作不增加一键执行；普通聊天、网页输入框、非交互 `exec -p` 和子 agent 行为不变。

## 实现约束

- 复用现有 `slash()` 的业务函数，避免交互路径和显式参数路径出现两套切换逻辑。
- 异步清单加载与提交防重：重复 Enter 只执行一次；加载失败、空列表、选中项中途消失都要可恢复或清楚退出。
- 保留正在生成时的命令排队规则；选择器未真正开始前不能吞掉用户消息。
- 只改 CLI、测试和说明；网页静态资源不变，因此不换缓存令牌。不调用付费模型，不自动发布 npm、部署或提交 Git。
