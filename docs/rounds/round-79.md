## 结果
**样子挪进样式表**
- `knowledge-wiki.html` 21 → 0、`pages/knowledge-wiki.js` 75 → 1（图谱图例的类型色 `--c`，是数据），JS 里改样子 14 → 0。全站内联样式 176 → **81**，第 9 步的目标（100 以内）到了；`InlineStyleRatchetTest` 加了一条总数 ≤ 100。
- 骨架：`.zq-wiki-cols`、`.zq-wiki-side`（目录 210、页面检查 250，`setupPanels` 照旧读算出来的 `flex-basis`）、`.zq-wiki-doc`、`.zq-wiki-tabbar`、`#zq-wiki-tabs`、`.zq-wiki-nav`、`.zq-wiki-head`、`#zq-doc`（和原来那条 `overflow-anchor:none` 并成一条）。「待合入变更」按钮是 `.zq-btn-ghost.zq-wiki-pending`。
- 状态的样子跟着状态走：目录和标签页的当前项是 `aria-current="page"`；正文的光标看 `aria-readonly`（原来 JS 写 `style.cursor`）、页名能改名时的手指看 `title` 是不是空（只读 / 加载中时 `syncWikiEditMode` 把它清空）；
  前进 / 返回没历史时的灰在 `:disabled` 上（原来 JS 写 `opacity`，顺带：灰着的时候光标不再是手指）；勾上的任务项划线本来就在样式表里，JS 那两行是重复的，删了；导入来源的「文本 / 上传」两块用 `hidden` 切。
- 弹窗里的说明、提示、列表收成几个类（`.zq-wiki-note`、`.zq-wiki-hint`、`.zq-wiki-list`、`.zq-wiki-source`、`.zq-wiki-issue`、`.zq-graph*`、`.zq-patch*`）；标签栏的「+」从字符换成 `ICONS` 的 `plus`。
- 字号：目录、标签、弹窗里的 12.5 → 13、11.5 → 12、10.5 / 11 → `--zq-fs-2xs`。写死的字号种数没少（这几种别处还在用：看板、共用层、落地页）。
