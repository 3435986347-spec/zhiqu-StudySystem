# 第一百一十六轮（2026-11-07）：生成文件到 artifact（桌面版和服务器网页版同一份）

## 由来
用户：「网页版不能操作磁盘，但是可以生成文件到artifact啊」「同时桌面版应用也可以生成文件到artifact」。服务器上跑命令是下一轮，这一轮服务器只生成文件。

## 计划
1. 档位开着、没选文件夹，就是「生成到 artifact」。服务器上永远是这样（没有选文件夹的入口）。桌面版的项目菜单多一项「不选文件夹」。
2. 每段对话一个临时空间（不是用户的文件夹）：`write_file` / `edit_file` / `apply_patch` 直接写进去，不走草稿（没碰用户的东西，不用确认），`shell` 也跑在里面（桌面版，沿用系统沙箱），写的文件后面的命令看得到。
3. 这一轮结束比对前后，新增和改过的文件存进数据库（`ai_artifact_file`，几个后端连同一个库，换台电脑也打得开），挂在一个 `GENERATED_FILES` 产物上。有上限（单个 5MB、一次 20MB、一个账号 200MB），超了照实说没存。软链、管道这些不读。
4. 页面上：列出文件，能预览（文本、代码、Markdown、图片；HTML 关在没有同源权限的 iframe 里）、能下载（`attachment` + `nosniff`，不在本站打开）。只有本人能取。
5. 临时空间可以随时清（几天没动就删），接着聊时从数据库恢复。
6. 服务器默认还是关的（`app.workspace.hosted-enabled=false`），部署时打开；打开之后账号能切档位，但碰磁盘的接口照旧只认本机。陌生网页连桌面版的后端：还是开不了档位（只有生产 profile 才放开）。
7. 判据：真的 node 循环 + 真库；真浏览器里预览、下载；恶意文件（软链到密钥、管道、`../`、脚本型 HTML、超大文件）。

## 结果
做法写在 [`docs/notes/code-workspace.md`](../notes/code-workspace.md)「生成到产物」那段。计划照做，多了一条：

**真浏览器里发现的**
- **新的一轮一跑，上一轮生成的文件就点不到了**（面板只显示最近一轮的产物）。加了 `GET /api/ai/generated-files`，列「之前生成的文件」（每个路径最新的那份），换一轮、刷新、重启都还在。
- 手机上那一栏很窄：文件名被挤没、「下载」被切掉。放不下就换行，名字至少留 72px。
- 卡片标题和类型名重复（都是「生成的文件」）：改成「生成了 N 个文件」。

**真跑过的**（普通账号，默认配置的后端，假模型）
| 做什么 | 结果 |
|---|---|
| 不选文件夹开 auto | 不弹选文件夹的框，按钮写「生成到产物」，说明「文件会生成到产物里，能预览、下载」 |
| 模型写 `chart.html`、`logo.svg`、`docs/readme.md`、`main.py`，shell 跑 `python3 main.py > out.txt` | 5 个文件进数据库，模型下一步的 shell 看得到刚写的文件；不走草稿 |
| 预览 HTML（里面的脚本读 `parent.sessionStorage`） | 脚本跑了，`SecurityError`，令牌没拿到 |
| 预览 SVG（带 `<script>`）、Markdown（带 `onerror`） | 脚本没跑 |
| 下载 | `attachment` + `nosniff` + `CSP: sandbox` + `no-store`；没登录 403；别人的、对不上的文件都拒 |
| 恶意命令：软链到 `~/.ssh/id_rsa` 和 `/etc/passwd`、管道、6MB 文件、文件名 `<img src=x onerror=…>.txt` | 软链和管道不进产物、不卡；6MB 说「没存：超过单个文件 5MB 的上限」；文件名只是文字 |
| 那一栏收着时生成文件 | 自动打开（手机上不替他打开） |
| 重启后端、刷新 | 档位、文件都还在，能预览 |

扰动：第一批 102 处红 95、没落上 1（原文出现两处）。绿的 6 处：3 处防护多余（删了：目录不存在的判断、`overlay = null`、`pendingNote` 的覆盖），3 处样本不够（「先写再说」不该推、账号空间要逐个扣，补了）。复验 5 处全红。

判据：后端全量 1420（1 跳过写明原因）、命令行 436/436、评测工具 102 过 1 跳。

**还没做的、要知道的**
- 服务器上这一轮还跑不了命令，模型写的代码没有运行过，提示里让它照实说。下一轮做。
- 用户要重新选一次文件夹：开档位不再弹选文件夹的框，没选就是生成到产物，要文件夹点项目按钮。
- 页面上「预览」「下载」按钮和列表的接线靠真浏览器验的，node 判据只管画出来的内容和预览的种类。
- 账号删除时（目前只有软删）生成的文件没有一起删，留在表里占额度。
- 桌面应用要重新打包才带上。
