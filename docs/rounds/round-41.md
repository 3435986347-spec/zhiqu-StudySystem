# 第四十一轮（2026-10-06）：界面打磨第 1 步的调整 —— 黑白、字更细

## 由来
第四十轮的截图给用户看过。用户：「主要是文字可以像 claude 里面的一样，就是字体会细一点但是也能看清，然后主题就黑白的吧」。

## 计划

1. **强调色默认黑白**：浅色时强调色是近黑、深色时是近白；金色留作「界面风格」里的可选项（用户之前说过喜欢金色）。
   `:root` 换成浅色 + 黑白，金色变成 `html[data-zq-accent="gold"]` 那两块；头上那行和 `zhiqu-ui.js` 的默认值跟着换（存过 `gold` 的才是金色）；
   `<html>` 上写死的 `data-zq-accent` 也换。
2. **字更细，但看得清**（像 Claude 的应用）：字重整体降一档 —— 正文、导航项、标签、次要按钮、表头、菜单项、徽标 400；标题、主按钮、选中的导航 / 页签 500；
   600 只留给品牌标志和 Markdown 里的加粗（`b` / `strong` 原来是浏览器默认的 700，苹方的 Bold 很重）。正文颜色从近黑略微调柔，对比度仍 ≥ 4.5 : 1（判据算）。
   字号不动（上一轮刚按用户的意思小了一档）。
3. **判据**：`DesignTokensTest` 跟着「默认黑白、金色可选」改选择器；`theme-check.js` 的「默认金色」改成「默认黑白、存了 gold 才是金色」；
   新加一条：组件类里 600 的地方只有那几处（按选择器列出来，不是数个数）。各自扰动见红。
4. 截图（浅 / 深、看板 / AI 助手 / 任务 / Wiki / 设置）发给用户；桌面应用重新打包（强调色定了）。

### 怎么验
截图；全量通过、扰动见红；桌面应用重新打包。

## 结果（2026-10-06）

照计划做完，另外多做了一件（见第 3 条）。

1. **默认黑白**：`:root` 的强调色换成黑白那组、深色块换成近白那组，金色成了 `html[data-zq-accent="gold"]` 的两块（浅 / 深）。头上那行和 `zhiqu-ui.js` 只认存过 `gold` 的才是金色；
   `<html>` 上写死的改成 `data-zq-accent="mono"`；「界面风格」里强调色那一行改成「黑白、金色」的顺序。
2. **字更细**：样式表里的字重整体降一档（500 → 400、600 → 500），主按钮、危险按钮、选中的导航项 500，品牌标志 600；`b` / `strong` 定成 600（浏览器默认 700，苹方的粗体很重）。
   正文颜色 #18181B → #232326（浅）、#F4F4F5 → #ECECEE（深），对比度仍过（判据算的）。字号没动。
3. **页面里写死的字重也收了**（原计划里没有，看截图时发现：样式表里的字重降下来，页面里任务标题、卡片标题这些写在内联样式里的 600 / 700 还是很粗，用户要的「细一点」就只做了一半）：
   14 个页面 + 壳 + 设置弹窗 + 8 个页面模块里 95 处 `font-weight:600/700/800` → `var(--zq-fw-medium)`、`500/400` → `var(--zq-fw-regular)`。以后字重再调只改令牌。
4. **Wiki 的双链**：原来是强调色的字 + 一条淡淡的虚线下边框，黑白之后强调色就是正文的颜色、虚线又几乎看不见 —— 链接和正文分不出来。改成和外链一样的下划线（下划线用次要灰）。

**实测**（内置浏览器 1440×900）：浅 / 深的看板、AI 助手、任务、知识 Wiki。默认就是黑白（`data-zq-accent=mono`，主按钮近黑 / 近白）；计算出的字重：导航 400、选中的导航 500、标题 500；正文颜色 rgb(35,35,38)。

**判据**：`DesignTokensTest` 改成「默认黑白、金色可选」的选择器，新加两条 —— 「字更细」（半粗只在 `b,strong` 和 `.zq-brand-badge`，按选择器列；主按钮、选中导航、标题是中等；导航项和标签是常规）、
「内联字重只用令牌」（页面、模块、壳里不许写死数字字重，扫到的令牌不少于 80 处）；`theme-check.js` 的默认值跟着改。新判据第一次跑红了一条，是判据自己的错：
`.zq-side.is-collapsed .zq-nav a{…}` 里也有「.zq-nav a{」、还排在前面，正则先匹配到了它 —— 改成认行首。
扰动 6 个全红：标题用回半粗、导航项用回中等、头上那行默认又是金色、`zhiqu-ui.js` 默认又是金色、模块里又写死字重、正文颜色调得太浅（2.68 : 1）。
（「模块里又写死字重」第一次被扰动脚本跳过了 —— 那一行里同一个字串出现三次，脚本要求恰好一次；改成只换第一处、手动跑，红了。）

**验**：全量 978 / 0 / 0 / 0（开着 Docker）；桌面应用重新打包（签名、dmg 校验过，JAR 里是 `20261006-mono`、页面默认 `data-zq-accent="mono"`）。验证账号 `nav39_*` 留在 `zhiqu_verify` 里。
