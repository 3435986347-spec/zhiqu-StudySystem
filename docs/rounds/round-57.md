# 第五十七轮（2026-10-10）：界面打磨第 8 步（二）—— 参考计划、专注统计

## 由来
第 8 步「其余页面」分三轮（见第五十六轮）：这一轮参考计划和专注统计。

## 现在是什么样（验证账号：1 个已审核的参考计划，300 个任务，本周 6 分钟专注）
**参考计划**
- 筛选是一张卡片：「分类」「排序」「方向」三个带小标题的下拉 +「刷新」—— 「排序 + 方向」两个下拉才说清一件事；改了下拉就会重新取，「刷新」多余。
- 计划卡片：分类是一块彩色底的牌子；点赞数前面是字符「♡」当图标（界面规矩不许用 Unicode 符号当图标；`IconSetTest` 没扫到 JS 字符串里的这一个）。卡片只能用鼠标点，键盘到不了。
- 详情是写死在 HTML 里的另一套弹窗（自己的遮罩、×、内联样式，和别处 `openModal` 的样子不一样）：分类显示成代码「GENERAL」（卡片上是「通用规划」）；点赞是「♡ / ♥」；
  点赞之后整页重跑启动 —— 列表回到默认的分类和排序，下拉框里还显示着刚才选的。
- 「套用到我的日历」弹出一个文字框让人手打「YYYY-MM-DD」。
- 「我的投稿」「分享我的计划」弹窗的样子全是内联样式。这一页 58 处。

**专注统计**
- 柱状图：每一根上面都写数，零也写（「0 0 0 0 … 6」），零的柱子是一道灰线；唯一有数的那根是浅灰色，和零差不多。
- 「日 / 周 / 月」按下的样子是 JS 改 `style.background`；两张卡一高一矮（趋势那张比象限那张短一截）。页头没有说明。这一页 29 处内联样式。

## 计划
**参考计划**
1. 工具条一行：分类（全部 + 七类）一个下拉、排序一个下拉（最新发布 / 最早发布 / 赞最多），不要小标题（`aria-label`），不要「刷新」；右边写个数。
2. 卡片：分类是一个小圆点 + 名字（和看板「今天」的标签一样）；点赞是图标 `heart` + 数；卡片能用键盘打开（`role="button"`、`tabindex`、回车 / 空格）。网格 `auto-fill`，窄了一列。
3. 详情换成 `openModal`（删掉 HTML 里那一套）：分类写名字；点赞是图标按钮、按下 `aria-pressed`，点了只重新取列表、照着现在选的分类和排序；
   套用：弹窗里一个日期框（默认今天）+「套用到我的日历」—— 套用只执行一次的那几条原样留着（打开时生成键、键里带日期、请求在路上按钮不响应）。
4. 「我的投稿」「分享我的计划」的内联样式挪进样式表；选任务的列表和例行计划「从任务生成」用同一套（`.zq-pick-list` / `.zq-pick-row`，从 `.zq-rt-src*` 改名）。

**专注统计**
5. 柱子：有数的用强调色、上面写数；零的只留一道底线、不写「0」；每一根悬停说「哪天：多少分钟」。高度是数据，用 `--v`（0–1）交给样式表。
6. 「日 / 周 / 月」用 `.zq-seg` + `aria-pressed`；两张卡一样高；页头一行说明；内联样式挪进样式表。

**都要**
7. 判据：两页的画法在 node 里真跑（卡片 / 详情 / 点赞后照原筛选重新取 / 套用带键带日期且不重发；柱子零与非零、悬停说明、按下的分段）；页面结构（没有那套写死的弹窗、没有「刷新」和「方向」、没有内联样式、没有 Unicode 图标）；
   跟着改钉旧写法的判据（`InitErrorReplacesDemoContentTest` 的弹窗三处能关、`TaskFormTest` 的个数）。扰动见红。
8. 真浏览器：1440 / 960 / 手机、浅 / 深截图；暴力：连点套用、连点点赞、来回切分类和排序、日周月来回切。全量；桌面应用重新打包。

## 结果

**参考计划**
1. 工具条一行：分类（「全部分类」+ 七类）、排序（最新发布 / 最早发布 / 赞最多，一个下拉说清原来「排序」「方向」两个下拉的事），都只有 `aria-label`、不要小标题；没有「刷新」（改了就取）。页头按钮叫「分享我的计划」（和弹窗标题一样）。
2. 卡片：分类是小圆点 + 名字（点的颜色按壳里分类表的第三栏）、点赞是 `heart` 图标 + 数、底下写「适用：…」「套用过 N 次」（都没有就不画底栏；原来右下角那格是创建人，可列表接口不给，一直是空的）；
   卡片能用键盘打开（`role="button"`、`tabindex`、回车 / 空格），键盘移到时有焦点框。网格 `auto-fill`，窄了一列。
3. 详情换成 `openModal`（HTML 里那套写死的弹窗删了）：分类写名字（原来「GENERAL」）、来自谁、点赞是图标按钮（按下 `aria-pressed`，实心红心），点了只重新取列表、照着现在选的分类和排序（原来整页重跑启动，列表回到默认、下拉框里还是刚才选的）；
   套用：弹窗里一个日期框（默认今天）+「套用到我的日历」—— 「只执行一次」的三条原样（打开时生成键、键里带日期、请求在路上按钮不响应），另外没选日期不发、失败走 `safe`。
   `openModal` 先聚焦标了 `autofocus` 的（这里是日期框）—— 原来先聚焦第一个能点的，也就是「点赞」，一按回车就赞上了。
4. 「我的投稿」「分享我的计划」弹窗的内联样式挪进样式表；分享提交着不让再点，提交完「我的投稿」马上出现（原来要刷新）。选任务的列表和例行计划「从任务生成」用同一套（`.zq-pick-*`）。
5. 「♡」也在后台的参考计划审核里用着（`admin.js`）：换成「N 个赞」。`IconSetTest` 的符号名单加上「♡♥」—— 原来没有，扫过去是绿的（加上之后先红在这两处，修了才绿）。

**专注统计**
6. 柱子：有数的用强调色、上面写数；零只留一道底线、不写「0」；每一根悬停说「哪天：多少分钟」。高度是数据，用 `--v`（0–1）交给样式表（这一页唯一的 `style=`）。
7. 「日 / 周 / 月」是 `.zq-seg` + `aria-pressed`（原来 JS 改背景色）；两张卡一样高（都是 370px）；页头一行说明（「专注时长来自番茄钟的记录，任务数来自任务页。」）；四个数字、两张卡手机上怎么排写在 `zq-phone-2col` / `zq-phone-1col` 上。
8. 真浏览器照出来的：手机（柱子区 253px）和最窄的桌面窗口（354px）里十四根柱子底下的日期全被截成「9/」「10」。柱子那一块做成容器，窄于 460px 时隔一根写一个日期、写全（「9/27 9/29 10/1 …」，量过不重叠）。

**通用的小件**：第五十六轮在例行计划页起头的几样改成通用的名字 —— `.zq-card-head` / `.zq-card-note`、`.zq-pick-list` / `.zq-pick-row` / `.zq-pick-group`、`.zq-check-line`、`.zq-textarea-sm`、`.zq-btn-xs`（例行计划页跟着换，量过样子不变）。
内联 `style=` 全站 602 → 516（参考计划页 58 → 0，专注统计页 29 → 1）。缓存令牌 `20261010-plans`。

**判据**
- `shared-plans-check.js`（`SharedPlansLookTest`，import 发布的模块）：卡片、详情、我的投稿的画法；排序下拉的值；点赞连点只发一次、点完照原筛选重新取；套用没日期不发、连点只发一次、带打开时的键 + 日期、换日期换键、再打开是新键、失败不关。
- `statistics-check.js`（`StatisticsLookTest`）：零与非零、`--v`、悬停说明、转义、按下用 `aria-pressed`、图例（一个任务都没有时是 0% 不是 NaN）。两个 Java 类另管页面结构和样式表里那几条。
- 跟着改的：`InitErrorReplacesDemoContentTest` 的「参考计划弹窗三处能关」（弹窗删了，`openModal` 的关法 `SettingsDialogTest` 管着）；`DesignTokensTest`（60 → 45）、`MobileLayoutTest`（12 / 8 → 8 / 6）两个「没扫空」的下限，理由写在旁边（第 9 步换成棘轮）。
- 扰动 23 个全红（参考计划 15、专注统计 8）；模块里的 16 个逐个看过红在该红的那一条上。其中 P2（分类写回代码）在 Maven 那一趟里我写的原文多了一个引号、没落上被跳过，改对之后在逐个看的那一趟里红了（卡片和详情两条）。第一次跑扰动脚本时我把测试类名的变量起成了 `SP`，盖掉了脚本里放备份的路径，第一个扰动备份就失败退出了 —— 那时还没动任何文件，改名重跑。
