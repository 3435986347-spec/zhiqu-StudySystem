# 知趣 · 新前端页面（zhiqu-ui）

把「知趣·象限学习系统」的**前端显示整套替换**为成熟稳重的新版：14 个页面 + 一套公共
资源（CSS/JS）。**5 套配色风格 × 浅/深色**，全站宋体，侧边栏内实时切换并记忆。

> 本包只替换**前端显示**（HTML + CSS）。业务数据目前是页面内的**示例数据**，交互（切换、
> 折叠、表格状态流转、番茄钟、AI 流式对话、日期选择器）都是纯前端、可直接演示。
> **后端接口后续逐页接入**即可（每页数据都集中在页尾 `<script>` 的数组里，替换为接口返回值）。

---

## 一、目录结构

```
zhiqu-ui/

├── dashboard.html          看板（今日行动台 + 周历 + 象限摘要 + 番茄钟 + DDL）
├── tasks.html              任务列表（筛选 + 表格，状态可点按流转）
├── routines.html           例行计划（从任务生成 + 新建 + 我的例行）
├── statistics.html         学习统计（时长趋势柱图 + 象限分布环图）
├── achievement.html        成就系统（筛选 + 成就卡）

├── shared-plans.html       参考计划（卡片 + 详情弹窗，含主题化日期选择器）
├── knowledge-wiki.html     知识 Wiki（目录 / 文档 / 页面检查三栏，含 _index/_schema/_log）
├── ai-assistant.html       AI 助手（Notebook / 对话 / 执行轨迹三栏，流式对话）
├── admin.html              监管后台（指标 + 活跃趋势 + 运行状态）
├── account-admin.html      账号管理（表格，可禁用/启用）
├── feedback-admin.html     反馈管理（筛选 + 状态流转）

    └── zhiqu-ui.js         侧边导航 + 风格切换弹层 + 面板折叠
```

## 二、放进后端项目

把整个 `zhiqu-ui/` 里的文件覆盖到 `src/main/resources/static/` 对应位置：

- 14 个 `.html` → `static/`（同名覆盖现有页面）
- `assets/zhiqu-ui.css`、`assets/zhiqu-ui.js` → `static/assets/`

页面里已用 `href="assets/..."`、`src="assets/..."` 相对引用，放在 static 根下即可直接访问。

> 现有的 `css/`、`js/` 旧文件可保留（新页面不再引用它们）；确认无误后再删除以免混淆。

## 三、五套风格

侧边栏底部「界面风格」下拉切换，右侧按钮切浅/深色，选择存 `localStorage`（`zq.ver` / `zq.mode`），
刷新与换页保持一致，首帧前应用无闪白。

| 值 | 名称 | 气质 |
|----|------|------|
| v0 | 暖纸墨青 | 暖纸底 + 墨青，沉稳温润 |
| v1 | 石墨蓝 | 冷灰底 + 石墨蓝，标准专业后台（**默认**） |
| v2 | 纸墨松绿 | 米纸底 + 松墨绿，书房阅读感 |
| v3 | 黛紫·静雅 | 浅灰紫 + 黛紫，大圆角柔和 |
| v4 | 玄墨鎏金 | 中性底 + 鎏金强调，克制高级 |

## 四、后续接入接口（每页怎么接）

每个页面的示例数据都在页尾 `<script>` 里，形如 `var tasks=[…]; render();`。接入时：

1. 把写死的数组换成 `fetch('/api/...')` 的返回值；
2. 调用已有的 `render()` / `paint()` 重绘即可，DOM 结构不用动。

按钮/表单目前是纯展示，接后端时在对应 `onclick` 里补 `fetch` 提交即可。登录页
`index.html` 的表单加上提交逻辑即可对接现有登录接口。

## 五、说明

- 字体用在线 Google Fonts（Noto Serif SC）。若内网无外网，请把宋体字体文件自托管到
  `static/` 并改 `zhiqu-ui.css` 顶部字体栈（系统已回退到 Songti SC / SimSun）。
- 纯前端替换，不涉及任何 Java / 接口 / 数据库改动。
